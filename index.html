Операції над файлами, папками, ярликами

Практична робота на власному комп’ютері. Створюємо папки й файли, перейменовуємо, переміщуємо, створюємо ярлик, видаляємо та відновлюємо.

🖥️ Працюємо самостійно

Усі дії виконуй у навчальній папці. Не перейменовуй, не переміщуй і не видаляй особисті важливі або системні файли.
  1. Відкрий Провідник: Win+E.
  2. Відкрий Документи.
  3. Створи папку Урок_13_Прізвище.
  4. Усі завдання виконуй усередині неї.

3–7 хв

📁 Створюємо структуру папок

У робочій папці створи три папки:

01_Документи
текстові файли
02_Зображення
малюнки та фото
03_Мої_роботи
готові роботи
  1. Правою кнопкою у вільному місці → Створити → Папку.
  2. Введи назву → Enter.
  3. Повтори для всіх трьох папок.
2
7–12 хв

📄 Створюємо файл

У 01_Документи створи текстовий файл.

  1. Правою кнопкою → Створити → Текстовий документ.
  2. Назви його Моя_перша_робота.txt.
  3. Відкрий і введи: Я вмію працювати з файлами!
  4. Збережи та закрий.
3
12–16 хв

✏️ Перейменовуємо

Зміни назву Моя_перша_робота.txt на Моя_робота_5_клас.txt.

Швидко: виділи файл → F2 → нова назва → Enter.
Інший спосіб: права кнопка → Перейменувати → нова назва.

Перевір: файл залишився в 01_Документи, текст не зник.

4
16–21 хв

📦 Переміщуємо файл

Перемісти Моя_робота_5_клас.txt з 01_Документи до 03_Мої_роботи.

  1. Виділи файл.
  2. Ctrl+X.
  3. Відкрий 03_Мої_роботи.
  4. Ctrl+V.
Доказ: у старій папці файла немає, у новій він є. Назва та вміст не змінилися.

21–26 хв

🔗 Створюємо ярлик

Створи ярлик папки 03_Мої_роботи на Робочому столі.

  1. Правою кнопкою по папці.
  2. За потреби: Показати додаткові параметри.
  3. Надіслати → Робочий стіл (створити ярлик).
  4. Двічі клацни ярлик і перевір, що відкривається потрібна папка.
Увага: ярлик — не копія папки. Саму папку не видаляй.
6
26–30 хв

♻️ Видаляємо та відновлюємо ярлик

Працюй тільки з навчальним ярликом.

  1. Правою кнопкою по ярлику на Робочому столі → Видалити.
  2. Відкрий Кошик.
  3. Знайди свій ярлик → права кнопка → Відновити.
  4. Перевір, що ярлик знову на Робочому столі.
Висновок: відновлення повертає видалений об’єкт із Кошика.
30–35 хв • Самостійна місія

🏆 Наведи порядок без покрокової підказки

1. Назва

У 03_Мої_роботи перейменуй файл на Інформатика_5_клас.txt.

2. Переміщення

Створи в 02_Зображення файл Мій_малюнок.txt, потім перемісти його до 03_Мої_роботи.

3. Ярлик

Перевір, що на Робочому столі є ярлик до 03_Мої_роботи. Якщо немає — створи.

4. Кошик

Перевір Кошик. Якщо там залишився твій навчальний ярлик — віднови його.

Фінальний результат: покажи вчителю робочу папку, три папки всередині та справжні файли на своєму комп’ютері.
