02 · SMART LAB

Теорія: інтерфейс, огляд і 3D-перетворення

Навчальна мета: орієнтуватися в інтерфейсі Blender, розрізняти навігацію та трансформацію, точно переміщувати, обертати, масштабувати, віддзеркалювати й дублювати 3D-об’єкти.

3D Viewport

Основна область сцени. Тут видно моделі, осі координат, камеру та освітлення.

Outliner

Список об’єктів і колекцій сцени. Допомагає знаходити та виділяти елементи.

Properties

Властивості активного об’єкта, матеріалів, модифікаторів і сцени.

Навігація ≠ трансформація

Навігація змінює точку, з якої ми дивимося на сцену: обертання огляду середньою кнопкою миші, зсув огляду Shift + середня кнопка, наближення коліщатком. Трансформація змінює сам об’єкт: положення, орієнтацію або розмір.

Швидкі команди

G — перемістити; R — обернути; S — масштабувати; Shift+D — незалежний дублікат; Alt+D — пов’язаний дублікат; Ctrl+S — зберегти.

Після G/R/S можна натиснути X, Y або Z, щоб обмежити операцію віссю, а потім увести число.

Ракурси та огляд

NumPad 1 — спереду; NumPad 3 — справа; NumPad 7 — згори; NumPad 0 — камера; NumPad 5 — перемикання перспективи.

На ноутбуках без цифрового блока скористайтеся навігаційним гізмо або налаштуванням Emulate Numpad.

Точна трансформація

G → X → 2 → Enter    # переміщення на +2 по X
R → Z → 45 → Enter   # обертання на 45° навколо Z
S → 1.5 → Enter      # збільшення у 1,5 раза
S → X → -1 → Enter   # дзеркальне масштабування по X
Shift + D → Y → 3 → Enter  # незалежний дублікат
Поширені помилки: плутати масштаб огляду й масштаб об’єкта; змінювати не той об’єкт без виділення; натискати цифри до вибору осі; забувати підтвердити Enter; вважати Alt+D і Shift+D однаковими; не перевіряти результат після віддзеркалення. Зовнішній вигляд симетричного куба може приховувати ефект дзеркала — для перевірки потрібна асиметрична форма або позначка.

04 · SMART LAB

Практична робота · 8 кроків

Практична робота «Мінісцена з двома кубами». Виконуйте в Blender, працюйте самостійно та зберігайте файл після важливих кроків.

  1. Відкрий Blender та перевір, що працюєш у Object Mode. Збережи новий файл як 11_21_3D_Прізвище.blend.
  2. У 3D Viewport виділи куб лівою кнопкою миші; знайди його в Outliner.
  3. Натисни G, X, 2, Enter — перемісти куб на 2 одиниці вздовж осі X.
  4. Натисни R, Z, 45, Enter — поверни куб навколо осі Z на 45°.
  5. Натисни S, 1.5, Enter — збільш куб у півтора раза.
  6. Натисни Shift+D, Y, 3, Enter — створи незалежний дублікат зі зміщенням по Y.
  7. Для копії виконай S, X, -1, Enter — дзеркальне масштабування по осі X. Порівняй із початковим об’єктом.
  8. Перевір вигляд спереду (NumPad 1), згори (NumPad 7), збережи .blend і зроби скриншот результату.

Критерії успіху

Правильне виділення — 2 бали; точне переміщення й обертання — 3; масштабування та дзеркало — 3; незалежний дублікат — 2; збережений файл і пояснення — 2. Разом 12 балів.

Безпека

Робіть короткі перерви для очей, не встановлюйте неперевірені додатки, не публікуйте особисті дані в назвах файлів. Працюйте лише з дозволеним програмним забезпеченням.
