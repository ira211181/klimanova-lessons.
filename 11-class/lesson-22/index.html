Теорія →
02 · Теорія

Примітиви — будівельні блоки 3D-світу

Тривимірний примітив — базовий геометричний об’єкт, з якого можна скласти складнішу модель. У Blender примітиви-сітки додають у режимі Object Mode через Shift+A → Mesh. Положення 3D-курсора впливає на місце створення нового об’єкта.

Cube · Куб

Коробки, сидіння, будинки. Має шість граней у початковій формі.

UV Sphere · Сфера

М’ячі, кулі ліхтарів, крони дерев. Має сітку з кільцями та сегментами.

Cylinder · Циліндр

Стовпи, колони, стовбури. Має дві круглі основи.

Cone · Конус

Загострені дахи, ялинки, маркери. Має основу та вершину.

Plane · Площина

Основа сцени, доріжка, стіна; плоска сітка без товщини.

Icosphere · Ікосфера

Низькополігональні камені та стилізовані крони з трикутних граней.

Точне розміщення

Вісь X зазвичай позначена червоним, Y — зеленим, Z — синім. Location задає положення, Rotation — поворот, Scale — масштаб. Розміри після масштабування можна перевірити у панелі Item (N). Увага: масштаб об’єкта й фактичні розміри сітки — не одне й те саме.

Shift + A → Mesh → Cube     # додати куб
G → X → 2 → Enter           # змістити куб уздовж X на 2
S → Z → 0.5 → Enter         # зменшити висоту вдвічі
Shift + D → Y → 3 → Enter   # створити незалежну копію
F2 → «Опора_01»             # перейменувати активний об'єкт
Ctrl + S                   # зберегти .blend

Об’єкт проти сітки

У Object Mode ви працюєте з цілим об’єктом. У Edit Mode змінюєте вершини, ребра та грані сітки. Клавіша Tab перемикає режими.

Типові помилки

Додавати примітив у несподіваній точці через зміщений 3D-курсор; плутати обертання огляду з обертанням об’єкта; забувати Enter; залишати назви Cube.001; не зберігати файл.

Практика →
04 · Практична робота

«Мініпарк майбутнього» в Blender

Створіть сцену з простих форм: доріжка, лавка, дерево й ліхтар. Збережіть власний файл 11_22_Minipark.blend. Орієнтовний час — 20–25 хвилин.

  1. Відкрийте Blender, перевірте Object Mode, збережіть порожню сцену у своїй папці.
  2. Додайте Plane (Shift+A → Mesh → Plane), масштабуйте для основи парку, назвіть «Основа».
  3. Додайте Cube, масштабуйте його як сидіння лавки (довге, низьке).
  4. Додайте два окремі Cube для опор лавки; точно розмістіть їх під сидінням.
  5. Додайте Cylinder для стовбура дерева; збільште висоту вздовж Z.
  6. Додайте UV Sphere або Icosphere для крони; підніміть над стовбуром.
  7. Створіть ліхтар із Cylinder та UV Sphere; надайте об’єктам зрозумілі назви, перевірте перетини й масштаб.
  8. Огляньте сцену з трьох ракурсів, збережіть .blend, зробіть знімок екрана і поясніть вибір примітивів.
4 бали

Наявні 4 змістові частини сцени й правильно вибрані примітиви.

4 бали

Точне розміщення, масштаб, зрозумілі назви, охайна композиція.

4 бали

Збережений файл, самостійність, пояснення та перевірка результату.

Диференціація: базовий рівень — лавка й дерево; достатній — додайте ліхтар; високий — створіть симетричну алею з повторюваних об’єктів.
