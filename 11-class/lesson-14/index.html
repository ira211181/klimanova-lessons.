01

Теорія: від плану до працездатного сайту

Мета: реалізувати мінімальний вебпроєкт, перевірити основні функції, усунути помилки й задокументувати результати.

1. Реалізація

Семантична HTML-структура, зрозумілі тексти, CSS для різних екранів, перевірені посилання.

2. Тестування

Позитивні й негативні сценарії, клавіатурна навігація, мобільний вигляд, повідомлення форм.

3. Покращення

Фіксація дефектів, виправлення, повторна перевірка та оцінка ризиків приватності.

Приклад семантичної розмітки

<header><h1>Екопортал</h1></header>
<main>
  <section aria-labelledby="about">
    <h2 id="about">Про ініціативу</h2>
    <p>Дбаємо про довкілля.</p>
  </section>
</main>
<footer>Навчальний проєкт</footer>

Тест-кейс

Умова: форма містить обов'язкове поле.

Дія: залишити поле порожнім і натиснути кнопку.

Очікування: браузер не дозволить відправити порожню форму.

Висновок: тест пройдено / не пройдено.

Типові помилки: фіксована ширина для всіх екранів, непідписані поля, посилання «#» замість реальної адреси, неперевірені кнопки, збирання зайвих персональних даних. Безпека: не публікуй паролі, телефони чи адреси однокласників.

03

Практична робота «Екопортал ліцею»

Створи локальний односторінковий вебсайт про екологічну ініціативу. Не використовуй персональні дані та не завантажуй учнівські фотографії без дозволу.

  1. Підготуй структуру. Створи папку eco-portal та файл index.html.
  2. Додай семантику. Використай header, nav, main, section, footer.
  3. Наповни змістом. Додай мету ініціативи, три корисні поради й джерело відомостей.
  4. Створи навігацію. Додай посилання на два розділи за їхніми id та перевір переходи.
  5. Оформи CSS. Зроби читабельний контраст, гнучку сітку й медіазапит для смартфона.
  6. Додай взаємодію. Створи форму з підписаним полем і атрибутом required. Для навчальної версії не надсилай дані на сервер.
  7. Виконай тестування. Перевір посилання, порожню форму, коректний ввід, клавіатуру та ширину 375 px.
  8. Звітуй. Запиши три результати тестів, виправ одну помилку й продемонструй готову сторінку вчителю.
Критерії: структура й зміст — 3 бали; адаптивність — 2; форма та доступність — 3; тести й виправлення — 3; доброчесність — 1. Разом 12 балів.
