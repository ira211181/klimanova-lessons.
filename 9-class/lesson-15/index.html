02
Пояснення

Що таке список та індекс

Створення

Список — впорядкована змінювана послідовність. У Python його записують у квадратних дужках.

бали = [10, 11, 8, 12]
міста = ["Київ", "Львів"]
порожній = []

Індекси

Перший індекс — 0, другий — 1, -1 — останній елемент непорожнього списку.

a = [10, 20, 30]
print(a[0])  # 10
print(a[-1]) # 30

Довжина і додавання

a = [4, 6]
print(len(a)) # 2
a.append(8)
print(a) # [4, 6, 8]

len() рахує елементи, append() додає наприкінці.

Вставлення та зміна

a = [4, 8]
a.insert(1, 6)
a[0] = 2
print(a) # [2, 6, 8]

insert(i,x) вставляє перед індексом i.

Поширені помилки: починати індексацію з 1; звертатися за межі списку; плутати append() та insert(); забувати квадратні дужки.

Практична робота «Маршрут мрії»

Працюй у Python IDLE, Thonny або дозволеному вчителем середовищі. Не запускай невідомі скрипти та не вводь персональні дані.

  1. Створи файл marshrut.py.
  2. Уведи маршрут=["Київ","Львів","Одеса"].
  3. Виведи список командою print(маршрут).
  4. Виведи перше місто за індексом 0 й останнє за -1.
  5. Додай "Чернівці" через append().
  6. Встав "Полтава" на індекс 1 через insert().
  7. Заміни перше місто на "Харків" і виведи len(маршрут).
  8. Запусти, перевір і збережи програму. Поясни кожну дію.

Очікуваний результат: ['Харків', 'Полтава', 'Львів', 'Одеса', 'Чернівці'], довжина 5.
