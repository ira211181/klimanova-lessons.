Створення, опрацювання та виведення рядків

Продовжуємо тему «Рядкові величини»: сьогодні створюємо повний алгоритм введення → очищення → перетворення → аналіз → виведення. Уяви, що розробляєш форму реєстрації шкільного клубу.

Створення

s = input("Ім’я: ") читає текст із клавіатури. s = "Марія" задає рядок без введення.

Опрацювання

strip() очищує крайові пробіли; title() змінює регістр слів; replace() замінює фрагменти; find() шукає підрядок.

Виведення

print() показує результат. len(s) повертає кількість символів; count() рахує входження.

Схема текстового алгоритму

input()→strip()→title()→len() / find()→print()

Приклад Python 3

raw = input("Введіть ім'я: ")
name = raw.strip().title()
if name:
    print("Учасник:", name)
    print("Символів:", len(name))
    print("Є літера а:", "а" in name.lower())
else:
    print("Введіть непорожнє ім'я")

Поширені помилки

❌ input() повертає рядок, а не число. ❌ s.upper() сам по собі не змінює s: треба s = s.upper(). ❌ find() повертає -1, якщо фрагмента немає. ❌ Індекси символів починаються з нуля.

Практична робота «Картка учасника»

Мета: створити програму, що читає ім’я, очищує пробіли, нормалізує регістр, рахує символи та виводить результат.

Інструменти: Python 3 / IDLE. Не використовуй справжні персональні дані інших людей; роби перерви під час роботи.

  1. Створи файл club_card.py.
  2. Зчитай ім’я через input().
  3. Прибери крайові пробіли через strip().
  4. Застосуй title() і збережи результат.
  5. Виведи очищене ім’я через print().
  6. Виведи довжину через len().
  7. Перевір входження літери «а» оператором in після lower().
  8. Перевір введення « марія », «ОЛЕГ» та порожній рядок. Оброби порожнє значення.
raw = input("Ім'я: ")
name = raw.strip().title()
if name:
    print("Учасник:", name)
    print("Довжина:", len(name))
    print("Є а:", "а" in name.lower())
else:
    print("Введіть ім'я")

Приклад: « марія » → «Учасник: Марія», довжина 5, літера «а» є.

Самоперевірка (12 балів): введення (2), очищення (2), регістр (2), аналіз (2), виведення (2), тестування та пояснення (2).
