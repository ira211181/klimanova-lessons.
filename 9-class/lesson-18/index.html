01
Розбираємося в основах

Теорія без зайвого

Упорядкуємо результати гри, ціни товарів чи оцінки — і зрозуміємо різницю між двома схожими командами.

01 · Список

Змінювана впорядкована колекція елементів Python, наприклад [8, 3, 6].

02 · Сортування

Перестановка елементів за обраним правилом: за значенням, алфавітом тощо.

03 · Неспадання

Кожне наступне число не менше попереднього: 1, 3, 3, 8.

04 · Незростання

Кожне наступне число не більше попереднього: 8, 3, 3, 1.

05 · sort()

Метод змінює сам список. Результат методу — None.

06 · sorted()

Функція створює новий відсортований список. Початковий не змінює.

Порівняйте код

scores = [8, 3, 10, 5] new = sorted(scores) print(scores) # [8, 3, 10, 5] print(new) # [3, 5, 8, 10] scores.sort(reverse=True) print(scores) # [10, 8, 5, 3]

Схема прийняття рішення

Треба зберегти початковий порядок?

Так → sorted(a)Ні → a.sort()

Параметр reverse=True змінює напрям на спадання в обох випадках.

⚠ Типова помилка

a = a.sort() зробить a рівним None. Правильно: просто a.sort(), без присвоєння.

Зверніть увагу: sort() і sorted() використовують вбудоване ефективне сортування Python. Симулятор нижче показує два навчальні алгоритми — метод обміну і метод вибору; це не внутрішній механізм sort().

03
Виконуємо власноруч

Практична робота «Рейтинг результатів»

Використайте Python 3, IDLE або Thonny. Зіставте початкові й отримані результати, а не просто скопіюйте код.

Мета: правильно використовувати sort() і sorted(), уміти пояснити різницю. Обладнання: ПК із Python 3. Безпека: дотримуйтеся правил роботи за комп’ютером; не вводьте справжні персональні оцінки інших дітей.

Алгоритм виконання

  1. Створіть файл sort_scores.py.
  2. Запишіть список points = [11, 7, 12, 5, 9].
  3. Виведіть список до сортування.
  4. Збережіть результат sorted(points) в окрему змінну ascending.
  5. Створіть descending через sorted(points, reverse=True).
  6. Виведіть усі три списки. Перевірте, що points досі початковий.
  7. Виконайте points.sort() і порівняйте результат.
  8. Замініть одне число й повторіть дослід.

Приклад, який має працювати

points = [11, 7, 12, 5, 9] ascending = sorted(points) descending = sorted(points, reverse=True) print('Початок:', points) print('Зростання:', ascending) print('Спадання:', descending) points.sort() print('Після sort:', points)

🛠 Знайдіть помилку

Учень вважає: «Для сортування за неспаданням методом бульбашки треба міняти сусідів, якщо лівий менший за правий».

Про модель: сортування вибором тут знаходить мінімум/максимум у невпорядкованій частині й фіксує його на початку; сортування обміном порівнює сусідів і закріплює крайній елемент наприкінці. Це наочне трасування конкретних алгоритмів, а не імітація роботи вбудованого sort().
