01 · Теорія

Список

Упорядкована змінювана колекція елементів Python.

Сортування

Розміщення елементів за певним порядком.

За зростанням

Від меншого до більшого: 1, 3, 7.

За спаданням

Від більшого до меншого: 7, 3, 1.

sort()

Змінює наявний список на місці.

sorted()

Створює новий відсортований список.

Порівняй команди

scores = [8, 3, 10, 5]
scores.sort()              # [3, 5, 8, 10]
scores.sort(reverse=True) # [10, 8, 5, 3]
new_scores = sorted(scores) # новий список

Типова помилка: scores = scores.sort() присвоїть змінній None, оскільки метод sort() не повертає новий список.

Приклад із життя: упорядкування результатів змагання, цін товарів або прізвищ за абеткою.

03 · Практична робота «Рейтинг результатів»

Мета: навчитися впорядковувати дані та порівнювати способи сортування. Інструменти: Python 3 / Thonny / IDLE. Дотримуйся правил безпечної роботи за комп’ютером і роби короткі перерви.

  1. Відкрий середовище Python і створи файл sort_scores.py.
  2. Створи список балів [11, 7, 12, 5, 9].
  3. Виведи початковий список на екран.
  4. Застосуй sorted() для сортування за зростанням.
  5. Застосуй sorted(..., reverse=True) для сортування за спаданням.
  6. Використай sort() та перевір, що вихідний список змінився.
  7. Додай власне значення і повтори дослід.
points = [11, 7, 12, 5, 9]
print('Було:', points)
print('Зростання:', sorted(points))
print('Спадання:', sorted(points, reverse=True))
points.sort()
print('Після sort():', points)

Самоперевірка: отримано 5, 7, 9, 11, 12 за зростанням і 12, 11, 9, 7, 5 за спаданням.
