Мета та ключові поняття

Після уроку ви зможете написати програму для очищення й перетворення тексту, пояснити роботу str, split(), join(), strip(), зрізів та перевірити результат на кількох прикладах.

Рядок — str

Послідовність символів у лапках. Символи нумеруються від нуля; індекс -1 означає останній символ.

Незмінність

Методи не змінюють початковий рядок, а повертають новий. Результат потрібно зберегти у змінній.

Алгоритм

Введення → очищення → розбиття → перетворення → з'єднання → перевірка й виведення.

input()→strip()→split()→lower()/title()→join()→print()

Приклади, зрізи та типові помилки

Приклад 1. Очищення й слова

text = "  Мій   код  "
clean = text.strip()
words = clean.split()
print(words)           # ['Мій', 'код']
print(len(words))      # 2

Метод split() без аргументів розділяє за групами пробільних символів, тому декілька пробілів не створюють порожні слова.

Приклад 2. З'єднання

words = ["моя", "програма"]
result = " · ".join(words)
print(result)          # моя · програма
print(result[:3])      # моя

У зрізі [start:stop] символ із позицією stop не входить у результат.

Приклад 3. Перетворення регістру

raw = "  ПРИВІТ   СВІТ "
words = raw.strip().split()
new = " ".join(w.lower() for w in words)
print(new)             # привіт світ

Помилки, яких слід уникати

text.strip() без присвоєння не змінить text. words.join(" ") — неправильний виклик: пишіть " ".join(words). Метод find() повертає -1, коли підрядка немає. Не плутайте split() і split(" ") при повторних пробілах.

Зверніть увагу: len(text) рахує символи, а len(text.split()) — слова. Для українських символів Python 3 працює з рядками Unicode.

Практична робота «Редактор шкільних оголошень»

Завдання: створити програму, яка отримує рядок оголошення, очищує пробіли, нормалізує слова, виводить оформлений текст і кількість слів. Уникайте реальних імен та інших персональних даних.

  1. Відкрийте Python IDLE або інше дозволене середовище Python 3. Створіть файл practice_strings.py.
  2. Створіть змінну source і зчитайте речення з клавіатури через input(). Використовуйте лише вигадані приклади, без персональних даних.
  3. Застосуйте strip() і збережіть очищений рядок у новій змінній. Порівняйте початковий та очищений текст.
  4. Розділіть очищений рядок на слова методом split(). Виведіть список і кількість слів.
  5. Для кожного слова застосуйте lower() або title() відповідно до задуму програми.
  6. З'єднайте слова через ' · '.join(words). Виведіть результат і кількість його символів.
  7. Перевірте три набори даних: звичайний текст, рядок із зайвими пробілами та порожній рядок. Запишіть очікувані й фактичні результати.
  8. Збережіть .py-файл. Додайте 2–3 речення про те, яку помилку ви знайшли й як перевірили програму.

Заготовка для Python 3

source = input("Текст: ")
clean = source.strip()
words = clean.split()
normalized = [word.lower() for word in words]
result = " · ".join(normalized)
print("Слова:", len(words))
print("Результат:", result)

Оцінювання — 12 балів

2 б. — введення та збереження даних; 2 б. — очищення й розбиття; 2 б. — нормалізація та об'єднання; 2 б. — правильне виведення; 2 б. — три тести, зокрема порожній рядок; 2 б. — самостійність, пояснення й охайність коду.

Приклад перевірки: введення " ПЛАН КЛАСУ " → "план · класу"; кількість слів — 2.
