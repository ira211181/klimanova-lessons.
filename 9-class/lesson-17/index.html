🧠 Пригадай та застосуй

1. Список як модель даних

Список Python зберігає впорядковану послідовність значень. Елементи можуть повторюватися; індекси починаються з 0.

readings = [14, 12, 17, 11, 16, 13, 18, 15]
print(readings[0])  # 14
print(readings[-1]) # 15

2. Показники набору

sum() — сума, len() — кількість, min() і max() — крайні значення, count() — кількість входжень.

total = sum(readings)
average = total / len(readings)
print(total, average)  # 116 14.5

3. Умовний відбір

Перебираємо значення циклом for та підраховуємо ті, що задовольняють умову.

above = 0
for x in readings:
    if x > 15:
        above += 1
print(above)  # 3

4. Типові помилки

Не плутайте > з >=; не діліть на len([]); перевіряйте введення; не змінюйте список під час перебору без необхідності. Сортування залишаємо для наступного уроку.

if readings:
    print(sum(readings) / len(readings))
else:
    print("Немає даних")
Математика + інформатика: показники 8 днів [14, 12, 17, 11, 16, 13, 18, 15] мають суму 116, середнє 14,5; днів із показником строго більшим за 15 — три. Це умовні навчальні дані, не показники реальної школи.

Орієнтир для перевірки (не копіюй без розуміння)

readings = [14, 12, 17, 11, 16, 13, 18, 15]
if not readings:
    print("Немає даних")
else:
    print("Сума:", sum(readings))
    print("Середнє:", sum(readings) / len(readings))
    print("Мінімум:", min(readings))
    print("Максимум:", max(readings))
    count = 0
    for value in readings:
        if value > 15:
            count += 1
    print("Понад 15:", count)
Збережіть власний файл .py і скриншот результату. Самостійно поясніть одну перевірку. Працюйте лише з навчальними даними.
