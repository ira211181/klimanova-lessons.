01 · пояснюємо

Як створити, вивести та опрацювати список

Список (list) — змінювана впорядкована колекція. Кожен елемент має індекс, що починається з 0. У списку можуть повторюватися значення.

Створення і виведення

values = [12, 8, 15] print(values) # [12, 8, 15] print(*values) # 12 8 15 print(values[0]) # 12 print(len(values)) # 3

Зірочка перед списком у print розпаковує його елементи.

Додавання та заміна

values = [12, 8, 15] values.append(7) values[1] = 10 print(values) # [12, 10, 15, 7]

append() додає елемент наприкінці, values[1] = 10 замінює другий.

Перебір і накопичення

values = [12, 8, 15] total = 0 for number in values: total += number print(total) # 35

Цикл for послідовно бере кожне значення зі списку.

Введення чисел одним рядком

line = input("Числа через пробіл: ") values = list(map(int, line.split())) print(*values)

split() дає рядки, int перетворює кожен із них на ціле число. Для некоректного введення потрібна обробка помилок.

Типові помилки. Для a=[4,9] елемента a[2] немає. input().split() без int не створює числа. append([2,3]) додає один вкладений список, а не два окремі числа.

03 · працюємо

Практична робота «Дані екоекспедиції»

Мета: створити програму, яка опрацьовує вимірювання умовної екоекспедиції. Працюйте в Python 3, IDLE або Thonny. Усі значення навчальні.

  1. Створіть файл eco_readings.py і додайте коментар з назвою роботи.
  2. Створіть список readings = [12, 8, 15, 7].
  3. Виведіть список командою print(readings), а далі — print(*readings); порівняйте результати.
  4. Виведіть перший, останній елемент і кількість значень (readings[0], readings[-1], len(readings)).
  5. Додайте нове вимірювання readings.append(10).
  6. Замініть другий елемент на 9 через присвоювання за індексом.
  7. Циклом for обчисліть суму та кількість вимірювань не менше 10.
  8. Перевірте роботу для списку [0, 10, 20]; збережіть код і коротко поясніть, чому перевіряли межові значення.
readings = [12, 8, 15, 7] readings.append(10) readings[1] = 9 total = 0 count = 0 for value in readings: total += value if value >= 10: count += 1 print("Усі:", *readings) print("Сума:", total, "Не менше 10:", count)

Самоперевірка для наведеного коду: список 12 9 15 7 10, сума 53, кількість значень не менше 10 — 3.

Симулятор «Екофільтр списку»

Це модель алгоритму, а не запуск Python. Вона показує, як цикл переглядає список і збирає значення, що відповідають умові value >= threshold.

Початковий список
Відібрані значення

selected = [] for value in readings: if value >= threshold: selected.append(value) print(*selected)

Порада: змініть поріг на 15, порівняйте вибірку, а потім поясніть, чому порядок елементів не змінився.
