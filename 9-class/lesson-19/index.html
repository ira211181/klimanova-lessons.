01

Мета та очікувані результати

Знаю

Оператори in, not in, методи count(), index(), індекси з нуля.

Умію

Шукати за умовою, обчислювати кількість збігів і знаходити всі позиції за допомогою enumerate().

Дотримуюся

Безпеки під час роботи, доброчесності й правил використання навчальних даних.

Мета: створити алгоритм пошуку в одновимірному списку, обґрунтувати умову відбору та перевірити результат.

02

Теорія: як працює пошук

1. Наявність значення

11 in values дає True, якщо число є у списку. 99 not in values — також True.

Оператор in не повертає індекс, лише логічне значення.

2. Кількість та перший індекс

values.count(11) → 2. values.index(11) → 1.

Якщо значення немає, index() викликає ValueError. Спочатку перевір in.

3. Пошук за умовою

Для кожного числа перевіряємо логічну умову, наприклад x > 10 або x % 2 == 0.

Результат можна зібрати у новий список без зміни вихідного.

4. Усі індекси

enumerate(values) дає пари «індекс, значення». Умова x == 11 дозволяє знайти всі позиції, а не лише першу.

Це важливо, коли збігів кілька.

Типові помилки: плутати значення та індекс; забувати про нульовий індекс; викликати index без перевірки; використовувати = замість ==; змінювати список під час перебору без необхідності.
03

Розбір коду Python

Знайдемо всі числа, більші за 10

values = [4, 11, 7, 15, 11, 2]
found = [x for x in values if x > 10]
print(found)             # [11, 15, 11]
print(len(found))        # 3
print(11 in values)      # True
print(values.count(11)) # 2

Знайдемо всі індекси числа 11

positions = []
for i, x in enumerate(values):
    if x == 11:
        positions.append(i)
print(positions)         # [1, 4]
Пояснення: список має два значення 11, їхні індекси — 1 і 4. Метод index(11) повернув би тільки 1.

Пошук першого збігу з достроковим виходом

for x in values:
    if x > 12:
        print("Перший збіг:", x)
        break
else:
    print("Збігів немає")

Блок else у циклі for виконується, якщо цикл завершився без break.

  4. Визнач усі позиції числа 11 за допомогою enumerate(books) і додавання індексів до нового списку.
  5. Створи новий список чисел, більших за 10, через генератор списку.
  6. Знайди суму відібраних чисел і кількість елементів; обґрунтуй результат.
  7. Заміни поріг 10 на 6. Запусти програму повторно, порівняй результати та поясни зміну.
  8. Збережи файл і короткий висновок. Використовуй лише вигадані навчальні дані, не персональні відомості.
