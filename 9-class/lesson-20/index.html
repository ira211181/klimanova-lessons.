01 · Орієнтири

Що ти навчишся робити?

Розуміти

Пояснювати тип str, незмінність рядків і правила індексації.

Застосовувати

Знаходити символи, утворювати зрізи та об’єднувати рядки.

Перевіряти

Передбачати результат коду, знаходити помилки й тестувати власні програми.

Пригадай: список теж є послідовністю. Але рядок зберігає символи й не дозволяє змінювати окремий символ за індексом.

02 · Теорія

Текст — це дані, з якими можна працювати

Рядок і тип str

Рядкова величина — послідовність символів у лапках. Навіть цифри в лапках є текстом, а не числом.

city = "Київ" year = "2026" print(type(city)) # str print(len(city)) # 4

Індексація

Перший символ має індекс 0, останній — -1. Звернення за межі рядка викликає IndexError.

s = "Мрія" print(s[0]) # М print(s[-1]) # я print(s[1]) # р

Зрізи та операції

s[start:stop] бере символи від start до stop, не включаючи stop. + об’єднує, * повторює.

s = "Python" print(s[:3]) # Pyt print(s[2:]) # thon print("інфо" + "рматика") print("ха" * 3) # хахаха

Методи та незмінність

upper(), lower(), strip(), replace() створюють нові рядки. Початковий не змінюється.

s = " привіт " clean = s.strip().upper() print(clean) # ПРИВІТ print(s) # з пробілами
Типові помилки: плутати 0 та 1; вважати, що stop входить у зріз; змінювати s[0] = "К"; використовувати індекс у порожньому рядку. Для безпечної перевірки спершу переконайся, що len(s) > 0.

Розбір прикладу

word = "Україна" print(len(word)) # 7 print(word[0:3]) # Укр print(word[-2:]) # на print("ї" in word) # True

Важливо: у Python len() для рядка рахує Unicode-кодові точки, а не байти. Деякі емодзі складаються з кількох кодових точок.

04 · Практична робота

«Текстовий навігатор»

Мета — написати програму, яка досліджує введене слово та виводить довжину, перший і останній символи, перші три символи й варіант великими літерами.

  1. Відкрий середовище Python (IDLE або інше доступне).
  2. Створи файл text_navigator.py.
  3. Запроси слово через input() та збережи його в word.
  4. Виведи довжину за допомогою len(word).
  5. Перевір if word: перед зверненням до першого й останнього символів.
  6. Виведи word[:3] та word.upper().
  7. Протестуй програму на «Київ», «Україна» та порожньому введенні.
  8. Збережи файл і коротко поясни, чому перевірка порожнього рядка потрібна.
word = input("Введи слово: ") print("Довжина:", len(word)) if word: print("Перший:", word[0]) print("Останній:", word[-1]) else: print("Рядок порожній") print("Перші три:", word[:3]) print("Великі літери:", word.upper())
Критерії (12 балів): правильний ввід і довжина — 2; індекси та перевірка порожнього рядка — 3; зріз і регістр — 3; тестування — 2; пояснення та оформлення — 2.

07 · Предметна симуляція

«Лабораторія рядків»

Змінюй текст і операцію. Симулятор показує етапи обробки, підсвічує символи та пояснює результат. Це модель операцій Python, а не виконання довільного коду.

Зміна рядка або операції скидає симуляцію. Для порожнього рядка індексація викликає IndexError.
