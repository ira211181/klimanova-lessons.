01 • Навчальна місія

Після уроку ти зможеш пояснити, що таке одновимірний масив, назвати індекс і значення елемента, розрізнити індекс і порядковий номер та скласти простий список у Python.

Знаю

Масив — впорядкований набір елементів; у Python для навчальних задач використовуємо list.

Умію

Знаходжу a[0], a[-1], довжину len(a) і змінюю значення елемента.

Безпека: працюй за комп'ютером з правильною поставою, не запускай невідомий код із мережі та роби короткі перерви.

02 • Теорія: один список — багато значень

Одновимірний масив — послідовність елементів, до яких звертаються за індексом. У Python найпоширеніший навчальний спосіб представлення такого набору — список (list). На відміну від строгого масиву, список Python може містити різні типи даних; у вправах використовуємо переважно числа.

Створення та індексація

marks = [10, 12, 8, 11]
print(marks[0])  # 10
print(marks[2])  # 8
print(len(marks)) # 4

Індекси починаються з 0. Останній додатний індекс — len(marks)-1.

Зміна елемента

marks = [10, 12, 8, 11]
marks[2] = 9
print(marks) # [10, 12, 9, 11]
print(marks[-1]) # 11

Індекс -1 звертається до останнього елемента списку.

Типові помилки

Помилка 1: marks[4] для чотирьох елементів — IndexError. Помилка 2: плутати кількість елементів (4) з останнім індексом (3). Помилка 3: записувати текстове число "5" замість числового 5, коли потрібні обчислення.

Мета: навчитися створювати й аналізувати одновимірний список. Працюй у Python-середовищі, доступному на шкільному комп'ютері, або в онлайн-редакторі, погодженому з учителем.

  1. Створи файл temperature.py і збережи у власній папці.
  2. Створи список temp = [12, 14, 11, 15, 13, 16, 10].
  3. Виведи список командою print(temp).
  4. Виведи температуру першого дня: print(temp[0]).
  5. Виведи температуру останнього дня: print(temp[-1]).
  6. Виведи кількість вимірювань: print(len(temp)).
  7. Зміни температуру третього дня на 12 через індекс і виведи оновлений список.
