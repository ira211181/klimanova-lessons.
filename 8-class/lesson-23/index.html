Що таке константа?

У програмі одні значення задають правила, інші надходять від користувача або обчислюються.

🔒 Константа

Величина, значення якої планують залишати сталим під час виконання програми: PRICE_PER_ITEM = 22.

🔁 Змінна

Величина, значення якої може змінюватися: quantity = 3, total = 81.

🧩 Домовленість Python

Імена констант пишуть ВЕЛИКИМИ_ЛІТЕРАМИ. Це стиль коду, а не технічна заборона переприсвоєння.

Важливе уточнення: звичайне присвоювання RATE = 10 не робить ім’я незмінним на рівні мови. Розробник домовляється не змінювати його в межах роботи програми.

Навіщо використовувати іменовані константи?

Щоб не повторювати «магічні числа» у формулах, легше читати код, уникати випадкових розбіжностей та змінювати правила між версіями програми. Уявімо майстерню, де одна наліпка коштує 22 грн, а пакування — 15 грн незалежно від кількості.

Модель: total = quantity * PRICE_PER_ITEM + PACK_FEE. Для 3 наліпок: 3 × 22 + 15 = 81 грн.

Приклад Python + Tkinter

Поле Entry приймає рядок. Перед обчисленням його потрібно перетворити та перевірити.

Мініпроєкт «Каса екомайстерні»

import tkinter as tk
from tkinter import messagebox

PRICE_PER_ITEM = 22  # стала ціна
PACK_FEE = 15        # стала плата за пакування

def calculate():
    try:
        quantity = int(entry.get().strip())
        if quantity <= 0:
            raise ValueError("Кількість має бути додатною")
        total = quantity * PRICE_PER_ITEM + PACK_FEE
        result.config(text=f"До сплати: {total} грн")
    except ValueError:
        messagebox.showerror("Помилка", "Введіть додатне ціле число")

root = tk.Tk()
root.title("Екомайстерня")
tk.Label(root, text="Кількість наліпок:").pack(pady=5)
entry = tk.Entry(root)
entry.pack(pady=5)
tk.Button(root, text="Обчислити", command=calculate).pack(pady=5)
result = tk.Label(root, text="Результат з’явиться тут")
result.pack(pady=5)
root.mainloop()
Типові помилки: const PRICE = 22 (такого синтаксису в Python немає); int(entry.get()) без перевірки помилок; використання quantity як константи; переприсвоєння PRICE_PER_ITEM у кожному натисканні кнопки.

Мініперевірка: що станеться, якщо ввести abc? Програма покаже повідомлення про помилку, а не аварійно завершиться.

Мета: створити віконний проєкт із двома константами, введенням кількості, обчисленням вартості та перевіркою помилок. Збережіть файл eco_shop.py.

  1. Створіть новий файл Python, підключіть tkinter та messagebox.
  2. Задайте PRICE_PER_ITEM = 22 і PACK_FEE = 15 у верхній частині файлу.
  3. Створіть вікно з назвою «Екомайстерня».
  4. Додайте Label із підказкою та Entry для кількості.
  5. Створіть кнопку «Обчислити» й обробник calculate().
  6. У функції прочитайте кількість, перетворіть її на int і перевірте, що вона додатна.
  7. Обчисліть total, виведіть у Label; для помилки використайте messagebox.showerror().
  8. Перевірте значення 1, 3, 0, -2, abc; зробіть висновок, що є сталим, а що змінним.
Тести: 1 → 37 грн; 3 → 81 грн.
Помилки: 0, -2, abc → повідомлення.
Критерії: вікно 2 б., константи 2 б., обчислення 3 б., перевірка 3 б., тести й пояснення 2 б. Разом 12.
