02
Пояснення • 9 хв

Поле введення — міст між людиною та програмою

Entry — графічний компонент бібліотеки Tkinter для введення або редагування одного рядка тексту. Коли людина вводить ім’я, місто чи кількість, програма може прочитати ці символи та виконати дію.

🧩 Label ≠ Entry

Label показує пояснення або результат, а Entry приймає текст від користувача. Для багаторядкового введення є інший компонент — Text.

🛠 Властивості поля

width=24 — орієнтовна ширина у знакомісцях; bg — тло; fg — колір символів; font — шрифт; show='*' — маскування символів.

📥 get()

entry.get() читає поточний вміст поля як рядок str. Для числових обчислень треба перевірити й перетворити текст.

✏️ delete() та insert()

entry.delete(0, END) очищує поле. entry.insert(0, 'Текст') вставляє рядок на початок.

Поширені помилки: плутати Entry з Label; писати command=handle() замість command=handle; перетворювати порожній рядок на число; вважати, що show='*' шифрує пароль. У Tkinter стандартний Entry не має вбудованої властивості placeholder.

Приклад: якщо користувач увів Олена , то entry.get().strip() поверне Олена без крайніх пробілів.

Код із поясненням • 5 хв

Перша форма «Привітання»

import tkinter as tk

def greet():
    name = name_entry.get().strip()
    if not name:
        result_label.config(text="Введіть ім’я!")
        return
    result_label.config(text="Вітаю, " + name + "!")

root = tk.Tk()
root.title("Привітання")
root.geometry("340x230")

tk.Label(root, text="Як тебе звати?").pack(pady=8)
name_entry = tk.Entry(root, width=24, font=("Arial", 12))
name_entry.pack(pady=6)
tk.Button(root, text="Привітати", command=greet).pack(pady=8)
result_label = tk.Label(root, text="Очікую на ім’я")
result_label.pack(pady=6)

root.mainloop()
Чому це працює? Кнопка викликає greet, функція зчитує поле через get(), прибирає пробіли та оновлює напис через config(text=...). Порожній ввід не приймається.
