SMART LAB / 8 клас

Напис Label: поняття та властивості

Що таке напис?

Label — віджет, який відображає повідомлення, заголовок або підпис у графічному вікні. На відміну від Entry, він не призначений для введення тексту користувачем.

Button запускає дію при натисканні, а Label переважно показує інформацію.

Властивості

text — вміст; fg — колір тексту; bg — колір тла; font — шрифт і кегль; width, height — розміри.

Методи pack() та place(x=…, y=…) розміщують напис.

Типові помилки: створити Label без pack() або place(); переплутати fg і bg; забути лапки навколо тексту; вибрати однакові кольори тла й символів. У різних операційних системах вигляд шрифтів може відрізнятися.

04
SMART LAB / 8 клас

Приклад програми

Цей код створює вікно, додає синій напис із білим текстом і запускає обробку подій.

from tkinter import Tk, Label

root = Tk()
root.title("Музей відкриттів")
root.geometry("500x240")

label = Label(root, text="Вітаємо в музеї!",
              bg="navy", fg="white",
              font=("Arial", 20))
label.pack(pady=35)

root.mainloop()

Пояснення: Tk() створює вікно, Label(...) — напис, pack() розміщує його, а mainloop() підтримує роботу програми. Для зміни тексту після створення можна викликати label.config(text="Новий напис").

Практична робота «Музей шкільних відкриттів»

Завдання: створити в Python IDLE вікно з трьома підписами для експозиції. Орієнтовний час — 20 хвилин.

  1. Відкрий IDLE, створи новий файл і збережи його як museum_label.py.
  2. Імпортуй класи Tk та Label з tkinter.
  3. Створи вікно розміром 550 × 330 пікселів із заголовком «Музей шкільних відкриттів».
  4. Створи перший Label: назва експозиції, шрифт Arial 20, контрастні кольори.
  5. Створи другий Label: короткий опис винаходу (одне-два речення).
  6. Створи третій Label: авторство та рік (можна вигаданий навчальний приклад, позначений як приклад).
  7. Розмісти написи методом pack(), добери відступи та перевір читабельність.
  8. Запусти проєкт, виправ помилки, збережи файл і продемонструй учителю.
