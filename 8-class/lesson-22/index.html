02
Теорія • 9 хв

Від форми до результату

Проєкт із уведенням даних і виведенням результатів — програма, яка отримує значення від користувача, опрацьовує їх за алгоритмом і показує зрозумілу відповідь.

📥 Уведення

Entry дає змогу ввести рядок. Метод get() повертає str, навіть якщо введено цифри.

🧠 Опрацювання

Після strip() і перевірки значень перетворюємо їх на float або int. Формула: вартість = ціна × кількість.

🖱 Подія

Button(command=calculate) запускає функцію після натискання. Дужки біля імені функції тут не потрібні.

📤 Виведення

Label відображає результат. Оновити текст можна через result.config(text=...).

Типові помилки: множити рядки замість чисел; не перевіряти порожнє поле; приймати від’ємну кількість; писати command=calculate(); показувати повідомлення «Помилка» без пояснення. Важливо: для грошових розрахунків у реальних системах краще застосовувати Decimal; тут float використано для навчального прикладу.

Алгоритм: зчитати → прибрати пропуски → перевірити → перетворити → обчислити → показати. Перевірка — частина алгоритму, а не необов’язкове доповнення.

04
Зразок • 6 хв

Працююча програма на Python Tkinter

Скопіюй код у Python 3 з підтримкою Tkinter. Уведи ціну та кількість, натисни «Обчислити» й перевір кілька різних наборів даних.

import tkinter as tk

def calculate():
    price_text = price_entry.get().strip()
    count_text = count_entry.get().strip()

    if not price_text or not count_text:
        result.config(text="Заповни обидва поля.")
        return

    try:
        price = float(price_text)
        count = int(count_text)
    except ValueError:
        result.config(text="Уведи числа: ціну та цілу кількість.")
        return

    if price < 0 or count < 0:
        result.config(text="Значення не можуть бути від’ємними.")
        return

    total = price * count
    result.config(text=f"Разом: {total:.2f} грн")

root = tk.Tk()
root.title("Каса шкільного ярмарку")
root.geometry("380x290")

tk.Label(root, text="Ціна товару, грн:").pack(pady=3)
price_entry = tk.Entry(root)
price_entry.pack()

tk.Label(root, text="Кількість товарів:").pack(pady=3)
count_entry = tk.Entry(root)
count_entry.pack()

tk.Button(root, text="Обчислити",
          command=calculate).pack(pady=12)
result = tk.Label(root, text="Уведи дані й натисни кнопку")
result.pack()

root.mainloop()
Прогноз: для ціни 15 і кількості 3 побачимо «Разом: 45.00 грн». Для «п'ять» замість кількості — підказку про помилку. Для нульової кількості — «Разом: 0.00 грн».

Практична робота • 12–15 хв

Мініпроєкт «Каса шкільного ярмарку»

Завдання: створити вікно, що приймає ціну й кількість товару та виводить суму. Робота виконується самостійно з дотриманням правил безпеки.

  1. Відкрий Python IDLE або інше середовище з підтримкою Tkinter. Створи файл yarmarok.py.
  2. Імпортуй tkinter, створи вікно, задай заголовок і розмір.
  3. Додай два підписи й два поля Entry для ціни та кількості.
  4. Створи Label для повідомлень і кнопку «Обчислити».
  5. Напиши функцію calculate: зчитування, strip(), перевірка порожніх полів.
  6. Додай try/except ValueError, перевірку від’ємних чисел, множення й форматування результату.
  7. Протестуй щонайменше п'ять випадків: (15;3), (0;5), (10;-1), порожнє поле, текст замість числа. Запиши очікувані й фактичні результати.
  8. Збережи програму, зроби скриншот вікна з правильним результатом і коротко поясни, як працює обробник кнопки.

4 бали

Створено вікно, два поля, кнопку й напис.

4 бали

Алгоритм правильно читає, перевіряє та обчислює дані.

4 бали

П'ять тестових випадків, збережений файл і зрозуміле пояснення.

Безпека: роби короткі перерви, не змінюй системні налаштування, не запускай невідомі файли. Для перевірки використовуй вигадані дані — особиста інформація не потрібна.

Працюємо відповідально
