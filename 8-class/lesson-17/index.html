01 · Потреби визначають конфігурацію

Конфігурація комп’ютера — сукупність його апаратних складових і характеристик. Для текстових документів, навчальних відео, роботи в дорозі та 3D-графіки потрібні різні ресурси. Спочатку визначають задачі користувача, далі — обмеження та вимоги.

Крок 1 · Потреби

Які програми? Скільки файлів? Чи потрібна мобільність?

Крок 2 · Обмеження

Бюджет, сумісність, живлення, габарити, можливість ремонту.

Крок 3 · Пояснення

Порівняйте рішення за критеріями та обґрунтуйте компроміси.

Для чого потрібна кожна складова?

RAMТимчасове зберігання активних данихМісткість і сумісність
SSDЗберігання програм і файлівМісткість, швидкість, інтерфейс

Вдалий аргумент

«Для шкільної бібліотеки достатньо збалансованого ПК з SSD та 8–16 ГБ RAM: він виконає офісні задачі без дорогого GPU».

Поширені помилки

  • Плутати RAM із SSD.
  • Обирати найдорожче без обґрунтування.
  • Ігнорувати сумісність, батарею та бюджет.
  • Вважати навчальні умовні бали реальними цінами.

02 · Україномовний тематичний відеоматеріал

Перегляньте практичний приклад добору ПК для людей різних професій. Відео створене до видання Ривкінда 2021 року; принципи аналізу потреб застосовні й сьогодні.

Якщо вбудоване відео недоступне, відкрийте відео на YouTube. Фактична мова озвучення й iframe-відтворення потребують додаткової перевірки.

Контрольне запитання 1 · Чому конфігурації для різних професій відрізняються?

Різні задачі потребують різної продуктивності, мобільності, обсягу пам’яті й графічних можливостей.

Контрольне запитання 2 · Чому не можна вибрати лише процесор?

Треба врахувати RAM, накопичувач, графіку, периферію, сумісність і бюджет.

03 · Практична робота «ПК для чотирьох місій»

Завдання: створіть у текстовому або табличному редакторі порівняльну таблицю конфігурацій для бібліотеки, відеомонтажера, журналіста в дорозі та 3D-лабораторії.

  1. Створіть файл 8_клас_добір_ПК.
  2. Створіть стовпці «Місія», «CPU», «RAM», «SSD», «GPU», «Формфактор», «Обґрунтування».
  3. Запишіть потреби користувача для кожної місії.
  4. Оберіть складові для шкільної бібліотеки й поясніть, чому вони достатні.
  5. Для монтажу відео визначте пріоритетні ресурси та порівняйте з бібліотекою.
  6. Для журналіста врахуйте мобільність, батарею й підключення.
  7. Для 3D-лабораторії обґрунтуйте RAM і GPU; перевірте модель у симуляторі.
  8. Напишіть висновок (4–6 речень), збережіть файл і надішліть учителю погодженим способом.
Безпека: не відкривайте корпус ПК під напругою. Це віртуальне навчальне завдання, без фізичного монтажу деталей.

Оцінювання (12 балів): 4 — правильний добір, 3 — аргументація, 2 — порівняння, 2 — таблиця, 1 — висновок та доброчесність.
