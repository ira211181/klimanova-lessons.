1. Що потрібно знати перед практичною?

Мета: створювати віконні застосунки з уведенням даних, обробкою подій і виведенням результату.

Entry

Поле

Користувач вводить текст. Метод get() повертає рядок, навіть коли введено цифри.

Label

Напис

Показує підказку або результат. config(text=...) змінює напис.

Button

Кнопка

Параметр command=calculate призначає функцію, що виконається після натискання.

Алгоритм події

  1. Увести ціну й кількість.
  2. Натиснути кнопку.
  3. Отримати рядки через get().
  4. Перевірити й перетворити дані на числа.
  5. Обчислити добуток.
  6. Показати результат у Label.

Типові помилки

❌ command=calculate() запускає функцію відразу.

❌ price.get()*qty.get() намагається множити рядки.

❌ int("три") викликає ValueError.

✅ Використовуй try/except, перевіряй від’ємні значення.

Безпека: не вводь у навчальні форми адреси, паролі чи телефони. Дотримуйся правил БЖД та роби перерви для очей.

2. Приклад коду «Каса шкільного ярмарку»

Зразок працює в Python із Tkinter. Зверни увагу на try/except і command=calculate.

import tkinter as tk

def calculate():
    try:
        price = float(price_entry.get().replace(",", "."))
        qty = int(qty_entry.get())
        if price < 0 or qty < 0:
            raise ValueError
        total = price * qty
        result.config(text=f"Разом: {total:.2f} грн")
    except ValueError:
        result.config(text="Перевірте введені дані!")

window = tk.Tk()
window.title("Каса шкільного ярмарку")
window.geometry("380x260")
tk.Label(window, text="Ціна, грн").pack()
price_entry = tk.Entry(window)
price_entry.pack()
tk.Label(window, text="Кількість, шт.").pack()
qty_entry = tk.Entry(window)
qty_entry.pack()
tk.Button(window, text="Обчислити",
          command=calculate).pack(pady=12)
result = tk.Label(window, text="Очікую на дані")
result.pack()
window.mainloop()

4. Практична робота «Каса шкільного ярмарку»

Завдання: створи віконний проєкт із двома полями, написами, кнопкою та перевіркою введення. Використовуй вигадані дані.

  1. Створи файл yarmarok.py та імпортуй Tkinter.
  2. Створи вікно з назвою «Каса шкільного ярмарку».
  3. Додай написи «Ціна» та «Кількість».
  4. Додай два поля Entry.
  5. Створи функцію calculate(), яка зчитує значення й перетворює їх на числа.
  6. Додай перевірку від’ємних значень та try/except ValueError.
  7. Створи кнопку з command=calculate, виведи суму через Label.config().
  8. Перевір 35×3 → 105; 0×5 → 0; порожнє поле → помилка; -2×3 → помилка. Збережи код і короткий висновок.
Критерії на 12 балів: інтерфейс — 3; правильне обчислення — 3; обробка помилок — 2; чотири тести — 2; оформлення та пояснення — 2.

Творче доповнення: додай кнопку «Очистити» або розрахунок знижки для п’яти й більше виробів.
