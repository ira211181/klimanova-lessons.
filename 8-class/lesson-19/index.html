02 · Пояснення

Кнопка як об’єкт графічного інтерфейсу

Кнопка (Button) — елемент керування, на який користувач натискає, щоб запустити певну дію. У Python модуль tkinter дає змогу створювати кнопки всередині вікна.

text

Напис на кнопці: text="Почати".

bg та fg

Колір фону й тексту: bg="blue", fg="white".

width та height

Розміри в текстових одиницях Tkinter, не пікселях.

pack()

Автоматично розміщує кнопку в доступному просторі вікна.

place(x=..., y=...)

Розташовує кнопку за координатами від лівого верхнього кута.

command=ім’я_функції

Вказує функцію, яка викликається після натискання кнопки.

Подія та обробник

Подія — дія користувача, наприклад натискання кнопки. Обробник — функція, яку програма запускає у відповідь. Запис command=on_click передає посилання на функцію; command=on_click() викликає її одразу під час створення кнопки — це поширена помилка.

Типові помилки: забули pack() або place() — кнопка не з’явиться; помилилися в назві функції — виникне помилка; вказали command=on_click() — дія виконається завчасно; не викликали mainloop() — вікно не працюватиме як очікується.

Порівняй: кнопка ініціює дію, а напис (Label) переважно показує інформацію. Наступний урок присвячений написам.

03 · Приклад

Перша кнопка у Tkinter

Приклад створює вікно, додає кнопку «Привітатися» й змінює її напис після натискання.

import tkinter as tk

root = tk.Tk()
root.title("Моя перша кнопка")
root.geometry("360x220")

def on_click():
    button.config(text="Вітаю! Натиснуто")

button = tk.Button(
    root,
    text="Привітатися",
    bg="royalblue",
    fg="white",
    width=20,
    command=on_click
)
button.pack(pady=40)
root.mainloop()

Розбір: tk.Tk() створює вікно; tk.Button(root, ...) — кнопку, яка належить цьому вікну; command=on_click задає обробник; button.pack(...) показує кнопку; root.mainloop() запускає цикл обробки подій.

Перевірка: заміни command=on_click на command=on_click() подумки. Яка дія відбудеться до натискання? Поясни причину.

05 · Практична робота

«Кнопка добрих новин»

Завдання: створи у Python IDLE вікно з кнопкою «Отримати новину», яка після натискання змінює напис на «Сьогодні я навчився створювати кнопки!».

  1. Відкрий IDLE → File → New File; створи файл knopka_novyn.py.
  2. Імпортуй tkinter та створи головне вікно root = tk.Tk().
  3. Установи заголовок і розмір вікна 420 × 260.
  4. Створи функцію show_news(), яка змінює текст кнопки через button.config(text=...).
  5. Створи кнопку з текстом «Отримати новину», синім тлом та білим текстом.
  6. Прив’яжи обробник через command=show_news і розмісти кнопку через pack(pady=45).
  7. Додай root.mainloop(), збережи файл та запусти F5.
  8. Перевір кнопку двічі, зміни її колір, зроби скриншот і поясни, що змінилося.
Безпека: не запускай невідомі файли, не вводь паролі чи особисті дані в навчальні приклади, роби короткі перерви та дотримуйся правил роботи за комп’ютером.

Критерії: вікно відкривається — 2 бали; кнопка видима — 2; властивості задані — 2; натискання запускає функцію — 3; тестування й пояснення — 3. Разом 12 балів.
