01Навіщо вміти створювати запити?

У шкільній бібліотеці, магазині, електронному журналі чи каталозі є багато даних. Запит на вибірку допомагає отримати потрібні записи й поля за визначеними правилами, не змінюючи вихідну таблицю.

Поясню

Різницю між таблицею, фільтром, запитом і результатом.

Створю

Запит із полями, умовами та сортуванням у конструкторі або SQL.

Перевірю

Чи відповідають отримані записи поставленій задачі.

Попередній урок: впорядкування, пошук і фільтрування даних. Сьогодні поєднуємо ці операції в окремому запиті.

02Від таблиці до вибірки

Таблиця «Книги»

Поля: Код (унікальний ідентифікатор), Назва, Автор, Рік, Жанр, Наявна. Кожен рядок — окремий запис.

Запит може показати лише назви й авторів книжок, виданих не раніше 2020 року.

Чотири рішення дослідника

  1. Що показати? Вибір полів.
  2. Звідки? Вибір таблиці.
  3. Які записи? Критерії відбору.
  4. У якому порядку? Сортування.

Важливо: збережений запит — це інструкція для отримання результату, а не друга незалежна копія таблиці. Якщо дані таблиці зміняться, результат повторного виконання запиту також може змінитися.

Безпека: навчальний приклад використовує вигадані записи. Не додавайте до відкритих навчальних файлів особисті дані учнів, адреси чи телефони.

03Мова SQL: чотири основні частини

SELECT [Назва], [Автор], [Рік] FROM [Книги] WHERE [Рік] >= 2020 AND [Наявна] = True ORDER BY [Назва] ASC;

SELECT / FROM

SELECT визначає стовпці результату; FROM указує таблицю. SELECT * означає всі поля.

WHERE / ORDER BY

WHERE залишає записи за критерієм; ORDER BY упорядковує. ASC — за зростанням, DESC — за спаданням.

Декілька умов

AND вимагає виконання всіх поєднаних умов, OR — принаймні однієї. Наприклад, [Жанр] = 'Наука' AND [Рік] >= 2020 залишить новіші наукові книжки. Умову для тексту записуємо з одинарними лапками. Назви полів у квадратних дужках зручні в Microsoft Access.

Синтаксис демонструє навчальний SQL у стилі Microsoft Access; в інших системах керування базами даних окремі деталі можуть відрізнятися.

04Поширені помилки

❌ Плутаємо відбір і видалення

SELECT лише отримує результат. Команда DELETE змінює дані — у цьому уроці її не використовуємо.

❌ Неправильний критерій

[Рік] > 2020 не включає 2020 рік. Для «з 2020 року включно» потрібно >= 2020.

❌ Текст без лапок

[Жанр] = Наука — неправильний запис текстової константи. Правильно: [Жанр] = 'Наука'.

❌ Не перевіряємо результат

Нуль записів не означає, що таблиця порожня. Можливо, жоден запис не задовольняє умови.

06Практична робота «Каталог шкільної бібліотеки»

Мета: створити й перевірити запит на вибірку в Microsoft Access або іншому доступному навчальному середовищі баз даних. Якщо немає програми, скористайтеся симулятором нижче та збережіть текст SQL.

  1. Створіть навчальну таблицю Книги з полями Код, Назва, Автор, Рік, Жанр, Наявна (або відкрийте надану вчителем).
  2. Внесіть щонайменше 8 вигаданих записів різних років і жанрів; поле Код зробіть унікальним.
  3. Відкрийте конструктор запитів і додайте таблицю Книги.
  4. Додайте поля Назва, Автор, Рік до результату.
  5. Задайте критерій [Рік] >= 2020 і виконайте запит.
  6. Додайте критерій [Наявна] = True; порівняйте кількість рядків до й після.
  7. Встановіть сортування за назвою за зростанням. Перевірте щонайменше три записи.
  8. Збережіть запит як Книги_2020_наявні, зробіть знімок результату або запишіть SQL та короткий висновок.

Працюй самостійно

Не копіюй чужі запити без розуміння. Пояснюй, чому обрав поля, критерії та сортування. Якщо використовуєш довідку, зазнач джерело.

Захищай дані

Не використовуй реальні персональні дані для вправ. Не змінюй записи в чужій базі, не запускай незнайомі команди, не передавай паролі.

Пам’ятай: точність запиту перевіряють не лише синтаксисом, а й відповідністю результату поставленій задачі.
