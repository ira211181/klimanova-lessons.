02

Теорія та приклади

1. Рівняння у таблиці

Для x²−25=0 введи x у A2, а у B2 формулу =A2^2-25. Шукай значення x, за якого B2 дорівнює 0.

Важливо: є два корені −5 і 5; підбір параметра може знайти лише один із них залежно від початкового наближення.

2. Система рівнянь

Наприклад, x+y=10 і 2x+y=14. Відніманням першого рівняння від другого одержуємо x=4, y=6. У таблиці можна обчислити нев’язки: =A2+B2-10 та =2*A2+B2-14.

Для системи з кількома змінними зручні інструменти оптимізації або чисельні методи; Goal Seek змінює лише одну клітинку.

3. Підбір параметра (Goal Seek)

В Excel: Дані → Аналіз «що-якщо» → Підбір параметра. Задай клітинку з формулою, значення 0 і клітинку, яку можна змінювати. Назви команд можуть відрізнятися між версіями та мовами інтерфейсу.

4. Оптимізація (Solver)

У задачі максимізації обери цільову функцію, змінні рішення та обмеження. У Microsoft Excel надбудову Solver («Пошук розв’язання») може знадобитися окремо активувати. У Google Таблицях стандартний Goal Seek/Solver може вимагати додатка — не плутай інструменти різних середовищ.

Приклад: матеріали для шкільної події

ВирібЗміннаВартістьЧасКористь (ум. бали)
Значокx20 грн0,5 год9
Плакатy30 грн1 год15

Максимізувати U=9x+15y за умов: 20x+30y≤240; 0,5x+y≤8; x≥3; 1≤y≤5; x,y — цілі невід’ємні числа.

В Excel, якщо x у B2, y у C2:
Витрати: =20*B2+30*C2
Час:     =0.5*B2+C2   (десятковий роздільник залежить від локалі)
Користь: =9*B2+15*C2
Типові помилки: плутати змінну з результатом формули; ігнорувати обмеження; забувати цілочисельність; вважати будь-який знайдений корінь єдиним; вводити крапку замість коми без урахування локалі.

04

Практична робота «Розумний план шкільної події»

Працюй у Microsoft Excel або LibreOffice Calc; у Google Таблицях можна виконати моделювання формулами, а доступність Goal Seek/Solver залежить від установлених додатків. Збережи власний файл 10kl_urok14_praktyka.xlsx (або формат редактора).

  1. Створи таблицю зі стовпцями «x — значки», «y — плакати», «Витрати», «Час», «Користь».
  2. Введи x=3, y=2 та формули =20*B2+30*C2, =0.5*B2+C2, =9*B2+15*C2 (з урахуванням локалі).
  3. Створи окрему модель рівняння: A5 — початкове x, B5 — =A5^2-25.
  4. Використай «Підбір параметра» для B5=0, змінюючи A5. Спробуй початкові значення 4 і −4; запиши обидва можливі корені.
  5. Розв’яжи вручну систему x+y=10, 2x+y=14. Перевір x=4, y=6 формулами нев’язок.
  6. Для оптимізації задай ціль максимізації користі та змінні x,y. Встанови всі п’ять умов, зокрема цілочисельність.
  7. Якщо Solver недоступний, перебери допустимі пари x,y за допомогою симулятора нижче або таблиці; знайди найбільше значення U.
  8. Перевір витрати, час, допустимість і поясни, чому обраний варіант кращий за два інші допустимі плани. Збережи файл і висновок.
Оцінювання /12: формули — 3; рівняння і система — 3; обмеження й оптимум — 4; висновок та оформлення — 2.
