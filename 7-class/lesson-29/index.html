01 · Мета, результати й безпека

Навчитися самостійно створювати проєкт, який змінює властивості вікна після подій і показує повідомлення.

Знати

Властивості title, geometry, bg; події <Button-1>, <KeyPress>.

Уміти

Написати два обробники, прив’язати їх до подій, протестувати різні сценарії.

Пояснювати

Як подія змінює стан вікна, чому важливі перевірка та збереження проєкту.

БЖД: дотримуйтесь правил роботи за комп’ютером, робіть перерви, не запускайте невідомих файлів і не вводьте особисті дані у прикладах.

02 · Коротка теорія: властивості, події, обробники

Властивості вікна

root.title("Назва") — заголовок; root.geometry("360x230+150+100") — розміри й положення; root.configure(bg="lightgray") — тло.

Подія та обробник

root.bind("<Button-1>", on_click) — ліве клацання; root.bind("<KeyPress>", on_key) — натискання клавіші. Функції отримують параметр event.

Повідомлення

messagebox.showinfo("Подія", "Ми вивчаємо програмування!") показує інформаційний діалог. Для запитання «Так/Ні» є askyesno().

Типові помилки

Забутий event у функції; пропущений mainloop(); неправильний рядок geometry(); клавіші не працюють через відсутність фокуса.

03 · Зразок програми для дослідження

Це авторський навчальний варіант практичної роботи на Python Tkinter. Початкові розміри достатні, щоб безпечно перевірити зміну станів.

from tkinter import Tk, messagebox

root = Tk()
root.title("Практична робота")
root.geometry("360x230+150+100")
root.configure(bg="lightgray")

def on_click(event):
    root.configure(bg="tomato")
    root.geometry("480x260+100+200")
    messagebox.showinfo("Подія", "Ми вивчаємо програмування!", parent=root)

def on_key(event):
    root.configure(bg="lightblue")
    root.geometry("400x240+150+130")

root.bind("<Button-1>", on_click)
root.bind("<KeyPress>", on_key)
root.focus_set()
root.mainloop()
Перевірка: клацніть по вільній області вікна — фон стане червоним і з’явиться повідомлення; натисніть клавішу — фон стане блакитним.
Важливо: у реальному Tkinter для клавіатурних подій вікно повинне мати фокус. Браузерний симулятор нижче лише моделює наслідки, а не запускає Python.

Завдання: створити програму, що має початковий сірий фон, реагує на клацання та клавішу і показує інформаційне повідомлення. Зберігайте проєкт у власній навчальній папці.

  1. Створіть новий файл praktychna_29.py у редакторі Python.

  3. Задайте заголовок «Практична робота», сіре тло та геометрію 360x230+150+100.

  6. Прив’яжіть обробники через bind(), установіть фокус і запустіть mainloop().
