Як створити проєкт з розгалуженнями

Мета: перетворити життєву задачу на алгоритм, обрати пріоритети умов і перевірити програму.

1. Дані

Програма отримує температуру, швидкість вітру і відповідь про дощ. Для порівняння чисел використовуй float().

2. Умови

if перевіряє першу умову; elif — наступну, якщо попередні хибні; else — випадок, коли нічого не підійшло.

3. Тести

Перевір не тільки типові значення, а й межі: 9.9 і 10 °C, 30 і 30.1 °C, 14.9 і 15 м/с.

Алгоритм у Python

temp = float(input("Температура, °C: "))
wind = float(input("Вітер, м/с: "))
rain = input("Дощ? так/ні: ").strip().lower() == "так"

if rain:
    result = "У приміщенні"
elif wind >= 15:
    result = "У приміщенні"
elif temp < 10:
    result = "Коротка прогулянка"
elif temp > 30:
    result = "Перенести на інший час"
else:
    result = "На подвір’ї"

print(result)

Типові помилки

❌ if wind = 15: — потрібне == для рівності.
❌ Забули : після умови.
❌ Не зробили відступ для команд.
❌ Порівняли рядок з числом без float().

Чому важливий порядок?

Якщо одночасно йде дощ і сильний вітер, спрацює перша гілка про дощ. Решта умов ланцюжка elif не перевірятиметься.

Навчальна модель спрощує реальні рішення щодо безпеки. У житті дотримуйся вказівок дорослих і офіційних попереджень.

Практична робота «Шкільний метеопорадник»

Створи в Python проєкт, який за погодними даними рекомендує формат активності. Не використовуй реальні персональні дані.

  1. Відкрий середовище Python та створи новий файл meteoporadnyk.py.
  2. Запиши вхідні дані: температура temp, вітер wind, дощ rain.
  3. Перетвори числові значення за допомогою float(input(...)).
  4. Склади ланцюжок if / elif / else за правилами з теорії.
  5. Для кожної гілки збережи повідомлення у змінну result.
  6. Виведи результат командою print(result).
  7. Перевір набори: (22, 3, так), (18, 17, ні), (7, 4, ні), (34, 4, ні), (23, 4, ні).
  8. Перевір межі (10 °C, 30 °C, 15 м/с), зроби висновок і збережи проєкт.
Критерії самооцінювання (12 балів): вхідні дані — 2; правильні умови та порядок — 4; повідомлення — 2; тестування — 3; пояснення результату — 1.
