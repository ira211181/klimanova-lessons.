2. Теорія та приклад

Декомпозиція — поділ задачі на підзадачі. Функція — іменована підпрограма, яку можна викликати повторно. Розгалуження визначає, яку дію виконати за умовою.

План

Введення → перевірка → результат.

Функція

def level(points): приймає аргумент.

Умова

if/elif/else обирає гілку.

def level(points):
    if points >= 75:
        return "Високий"
    elif points >= 50:
        return "Середній"
    else:
        return "Потрібна підтримка"

def report(name, points):
    print(name + ": " + level(points))

report("Оля", 75)
report("Іван", 49)

Результат: Оля: Високий і Іван: Потрібна підтримка. Функція level повертає рядок, а report його друкує.

Поширені помилки: пропущена двокрапка, неправильні відступи, плутанина між print та return, невдалий порядок порогів.
