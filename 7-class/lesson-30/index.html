Теорія: графіка у вікні

У графічному вікні Python можна малювати лінії, прямокутники, кола, багатокутники й написи. Для цього використаємо Canvas з бібліотеки tkinter. Мета — навчитися планувати малюнок як послідовність точних команд.

Координати

Початок (0, 0) — лівий верхній кут полотна. Вісь X спрямована праворуч, вісь Y — униз.

Лінія

create_line(x1, y1, x2, y2) з’єднує точки; параметр width задає товщину.

Прямокутник

create_rectangle(x1, y1, x2, y2) створює фігуру за протилежними кутами.

Овал

create_oval(x1, y1, x2, y2) малює овал у межах прямокутної області; за рівних ширини й висоти — коло.

Багатокутник

create_polygon(x1, y1, x2, y2, ...) з’єднує вершини замкненої фігури.

Текст

create_text(x, y, text='...') додає підпис; координати за замовчуванням задають центр напису.

Кольори та контури

fill — колір заливки, outline — колір контуру, width — товщина лінії чи контуру. Назви кольорів або HEX-коди можна задавати рядками.

Порядок команд важливий: об’єкти, створені пізніше, можуть перекривати попередні.

Типові помилки

Плутанина між X та Y, вихід за межі полотна, відсутні лапки навколо назви кольору, пропущений mainloop(), неправильний порядок малювання.

Порада: спершу накресли ескіз на папері й запиши координати ключових точок.

Приклад Python: маленький маяк

from tkinter import Tk, Canvas

root = Tk()
root.title("Мій маяк")
canvas = Canvas(root, width=400, height=300, bg="#e9f7ff")
canvas.pack()

canvas.create_rectangle(0, 230, 400, 300, fill="#b9dfb4", outline="")
canvas.create_polygon(150, 230, 180, 95, 220, 95, 250, 230,
                      fill="#f8fafc", outline="#234b7b", width=2)
canvas.create_rectangle(180, 178, 220, 230, fill="#3b82f6")
canvas.create_oval(188, 115, 212, 139, fill="#fbbf24")
canvas.create_line(200, 95, 320, 35, fill="#f59e0b", width=5)
canvas.create_text(200, 265, text="Світло знань", fill="#173a63")
root.mainloop()

Практична робота: «Маяк цифрового міста»

Створи власну композицію «Маяк цифрового міста» засобами Python. Робота розрахована на 15–20 хвилин. Зберігай файл після кожного важливого етапу.

  1. Відкрий Python IDLE або інше середовище Python 3. Створи файл mayak.py у власній навчальній папці.
  2. Імпортуй Tk та Canvas, створи вікно й полотно 400 × 300 пікселів.
  3. Додай фоновий прямокутник та дві лінії, які позначатимуть горизонт і промінь світла.
  4. Намалюй корпус маяка за допомогою create_polygon(), а двері — через create_rectangle().
  5. Створи кругле віконце create_oval() і підпис create_text().
  6. Виконай програму, перевір положення фігур і значення координат. Якщо об’єкт зник, перевір межі полотна.
  7. Додай власний об’єкт (хмару, човен або зірку), зміни два кольори. Запусти й порівняй результати.
  8. Збережи файл. Підготуй коротке пояснення, які команди та координати використано, і продемонструй результат учителю.

Критерії оцінювання (12 балів)

Вікно й Canvas — 2 бали; правильні координати та щонайменше 4 типи об’єктів — 4; кольори й композиція — 2; власний елемент — 2; перевірка та пояснення — 2.
