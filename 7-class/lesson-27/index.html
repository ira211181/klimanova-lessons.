02 · Що таке вікно повідомлення?

У Python Tkinter модуль messagebox створює діалогові вікна. Модальне вікно очікує реакції користувача: доки його не закрито, робота з основним вікном програми зазвичай призупинена.

ℹ️ showinfo(title, message)

Сповіщає про успішне завершення або результат дії.

Наприклад: «Файл збережено»

⚠️ showwarning(title, message)

Попереджає про можливу проблему чи небажану дію.

Наприклад: «Перевірте дані»

⛔ showerror(title, message)

Повідомляє про помилку, яку треба виправити.

Наприклад: «Файл не знайдено»

❓ askyesno(title, message)

Просить обрати «Так» або «Ні» та повертає True або False.

Наприклад: «Завершити роботу?»

Зверніть увагу на типові помилки

  • command=handler() викликає функцію одразу; для кнопки потрібно command=handler.
  • askyesno() повертає логічне значення, а не текст «Так» чи «Ні».
  • showinfo() не призначено для введення довільного тексту.
  • Не плутайте вікно повідомлення з головним вікном Tk().

03 · Розбираємо робочий приклад

Програма містить три кнопки. Дві показують повідомлення, третя запитує підтвердження й змінює напис залежно від відповіді.

from tkinter import Tk, Label, Button, messagebox

root = Tk()
root.title("Помічник школяра")
root.geometry("390x240")

status = Label(root, text="Оберіть дію")
status.pack(pady=12)

def info():
    messagebox.showinfo("Готово", "Роботу збережено!")

def warn():
    messagebox.showwarning("Увага", "Перевірте дані.")

def confirm():
    answer = messagebox.askyesno("Підтвердження", "Завершити?")
    status.config(text="Обрано: " + ("Так" if answer else "Ні"))

Button(root, text="Інформація", command=info).pack(pady=3)
Button(root, text="Попередження", command=warn).pack(pady=3)
Button(root, text="Запитання", command=confirm).pack(pady=3)

root.mainloop()
Пояснення: messagebox.askyesno() повертає True для «Так» і False для «Ні». Оператор if можна використати для різних дій.
Середовище: для запуску Tkinter потрібен Python з графічним інтерфейсом на комп'ютері. У деяких онлайн-редакторах вікна Tkinter недоступні.

05 · Практична робота «Помічник школяра»

Створіть невеликий застосунок з трьома кнопками, що показують різні діалоги. Орієнтуйтеся на код вище, але змініть назви, тексти й оформлення на власні.

  1. Створіть файл message_windows.py у середовищі Python, що підтримує Tkinter.
  2. Імпортуйте tkinter і messagebox, створіть головне вікно.
  3. Додайте напис із підказкою для користувача.
  4. Створіть функцію info(), яка викликає showinfo() після натискання кнопки.
  5. Створіть функцію warn(), яка викликає showwarning().
  6. Створіть функцію confirm(), що використовує askyesno() та змінює текст напису залежно від відповіді.
  7. Додайте три кнопки з command=info, command=warn, command=confirm і запустіть mainloop().
  8. Перевірте всі кнопки, відповіді «Так» і «Ні», збережіть файл та підготуйте короткий висновок.
Критерії оцінювання (12 балів): створення вікна й імпорт — 2; три коректні кнопки — 3; обробники — 3; логіка «Так/Ні» — 2; тестування та самостійне оформлення — 2.
