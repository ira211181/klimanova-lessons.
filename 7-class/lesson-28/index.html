01 · Мета та очікувані результати

Навчитися проєктувати безпечну взаємодію програми з користувачем за допомогою діалогів підтвердження.

Знати

Три результати

True, False, None та різницю між askyesno(), askokcancel(), askyesnocancel().

Уміти

Програмувати вибір

Писати обробник події, перевіряти відповідь, пояснювати наслідки.

Дотримуватися

Безпечної взаємодії

Безпека життєдіяльності: дотримуйтеся правил роботи за комп’ютером, не запускайте невідомі програми, не використовуйте справжні особисті дані в навчальних прикладах.

02 · Від двох відповідей до трьох

На попередньому уроці ми знайомилися з вікнами повідомлень. Сьогодні головне — правильно обробити відповідь користувача, особливо коли він відмовляється або скасовує дію.

askyesno()

Запитує «Так/Ні» та повертає True або False.

askokcancel()

Запитує «Гаразд/Скасувати» та повертає True або False.

askyesnocancel()

Дає три рішення: True («Так»), False («Ні»), None («Скасувати» або закриття діалогу).

showwarning() / showerror()

Показують попередження або помилку. Вони не замінюють запит на підтвердження.

Чому if answer: недостатньо?

У Python і False, і None трактуються як хибноподібні. Якщо в програмі тільки if answer: ... else: ..., то «Ні» та «Скасувати» потраплять до однієї гілки. Коли ці дії мають різні наслідки, потрібно окремо перевіряти answer is True, answer is False і answer is None.

Правило безпечного дизайну: «Скасувати» залишає дані та вікно без змін; незворотні дії виконують тільки після явного підтвердження.

Зміст узгоджено з темою КТП: «Вікна повідомлень та їх використання». Орієнтир КТП — пункт 2.6, завдання 5–16. Нумерацію сторінок видання тут не стверджуємо.

03 · Робочий приклад Python

У цьому прикладі кнопка відкриває діалог, а напис показує наслідок кожного рішення. Реального збереження або видалення немає: це безпечна навчальна модель.

from tkinter import Tk, Button, Label, messagebox

root = Tk()
root.title("Безпечне завершення")
root.geometry("390x220")
status = Label(root, text="Проєкт відкрито")
status.pack(pady=18)

def confirm_exit():
    answer = messagebox.askyesnocancel(
        "Завершити проєкт?",
        "Зберегти зміни перед виходом?",
        parent=root
    )
    if answer is True:
        status.config(text="Зміни збережено (навчальний приклад)")
        # Тут у реальному проєкті викликають збереження
    elif answer is False:
        status.config(text="Вихід без збереження (навчальний приклад)")
        # Тут у реальному проєкті можна закрити вікно
    else:
        status.config(text="Дію скасовано — працюємо далі")

Button(root, text="Завершити", command=confirm_exit).pack(pady=10)
root.mainloop()
Дослід: змініть відповідь у діалозі тричі та запишіть, як змінюється напис. Чому важливо мати три гілки?
Увага: Tkinter потребує графічного середовища Python. Не кожен браузерний інтерпретатор підтримує створення вікон.

05 · Практична робота «Безпечний вихід із редактора»

Створіть власний проєкт Tkinter з кнопкою «Завершити» та діалогом збереження змін. Робота виконується локально у Python IDLE або іншому середовищі з Tkinter.

  1. Створіть файл safe_exit.py і запишіть тему та мету в коментарі.
  2. Імпортуйте Tk, Button, Label, messagebox.
  3. Створіть головне вікно 390×220 з назвою «Безпечне завершення».
  4. Додайте напис зі станом «Проєкт відкрито».
  5. Оголосіть обробник confirm_exit() з викликом askyesnocancel().
  6. Окремо перевірте is True, is False, is None і змініть напис відповідно до відповіді.
  7. Додайте кнопку з command=confirm_exit та виклик root.mainloop().
  8. Протестуйте «Так», «Ні», «Скасувати» й закриття діалогу. Зробіть скриншот одного результату та короткий висновок.
Критерії оцінювання (12 балів): вікно та елементи — 2; коректний діалог — 2; три гілки — 3; тестування чотирьох сценаріїв — 3; зрозумілий код і висновок — 2.
