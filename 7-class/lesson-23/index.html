02

Теорія: перше вікно Python

GUI і Tkinter

Графічний інтерфейс користувача (GUI) — спосіб взаємодії через вікна, кнопки, написи та поля.

Tkinter — модуль Python для створення графічного інтерфейсу. tk.Tk() створює головне вікно.

Властивості

title() — заголовок.

geometry("400x250") — ширина × висота; використовуйте латинську x.

configure(bg="lightblue") — фон.

mainloop() — цикл подій.

Приклад програми

import tkinter as tk

root = tk.Tk()
root.title("Майстерня ідей")
root.geometry("480x300")
root.configure(bg="lightyellow")

tk.Label(root, text="Вітаю, сьомий клас!").pack(pady=20)
root.mainloop()
Типові помилки: відсутній імпорт; у geometry написано «×» замість «x»; пропущено дужки; не викликано mainloop(); онлайн-середовище не підтримує графічних вікон. Для роботи з Tkinter використовуйте локальний Python із графічною підтримкою.

Домашнє завдання трьох рівнів

Базовий

Створіть вікно 360×240 «Мій застосунок» із зеленим фоном. Поясніть чотири команди.

Достатній

Створіть «Космічну станцію» 500×300 із написом. Перевірте два варіанти розміру.

Високий
