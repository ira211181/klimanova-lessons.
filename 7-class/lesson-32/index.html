02

Мінітеорія перед практикою

Чотири поняття та приклад повного проєкту.

Процедура й параметри

Процедура — іменований блок команд, який можна викликати багато разів. У Python її визначають через def. Параметри записують у визначенні, а аргументи передають під час виклику.

Наприклад, draw_house(40, 120, 1, "red") передає координати, масштаб і колір даху.

Координати й перевірка

На Canvas точка (0, 0) розташована у верхньому лівому куті, вісь x іде вправо, y — униз. Фігури за межами полотна можуть обрізатися.

Тестуй size=1, size=0.5, позицію біля краю й некоректний size=0.

Повний приклад «Місто процедур»

Код можна скопіювати в IDLE або інше локальне середовище Python із підтримкою Tkinter. У браузерному симуляторі нижче Python не виконується — він демонструє ту саму геометрію засобами JavaScript.

import tkinter as tk

root = tk.Tk()
root.title("Місто процедур")
canvas = tk.Canvas(root, width=640, height=360, bg="#eaf7ff")
canvas.pack()

def draw_house(x, y, size, roof_color):
    if size <= 0:
        raise ValueError("Масштаб має бути додатним")
    w, h = 90 * size, 75 * size
    canvas.create_rectangle(x, y, x+w, y+h,
                            fill="#ffe4a8", outline="#28476c", width=2)
    canvas.create_polygon(x-8*size, y, x+w/2, y-42*size,
                          x+w+8*size, y, fill=roof_color, outline="#28476c")
    canvas.create_rectangle(x+14*size, y+15*size,
                            x+37*size, y+40*size, fill="#a8ddff")
    canvas.create_rectangle(x+56*size, y+32*size,
                            x+76*size, y+h, fill="#80553b")

draw_house(45, 180, 1, "#ee6d61")
draw_house(225, 160, 1.25, "#5b8dee")
draw_house(445, 205, 0.8, "#4cae89")
root.mainloop()

Типові помилки

Забута двокрапка після def; неправильний відступ; пропущений аргумент; Canvas не розміщено методом pack(); координати виходять за межі полотна; нульовий або від'ємний масштаб.

04

Практична робота «Вулиця майбутнього»

8 послідовних кроків · орієнтовно 18–20 хв.

  1. Створи папку «7_клас_урок_32» та файл city.py; запиши мету проєкту: «Вулиця з будинками, намальованими процедурою».
  2. Імпортуй tkinter, створи вікно Tk() і полотно Canvas розміром 640×360, розмісти його методом pack().
  3. Оголоси def draw_house(x, y, size, roof_color):; у тілі перевір, що size > 0, інакше повідом про некоректний аргумент.
  4. У процедурі намалюй прямокутник-основу, трикутний дах, вікно та двері; усі розміри помнож на size.
  5. Виклич процедуру щонайменше тричі з різними x, y, size і кольорами даху; не копіюй її тіло.
  6. Додай доріжку або дерево окремою процедурою; поясни, які параметри потрібні для повторного використання.
  7. Протестуй звичайний, малий і граничний варіанти; запиши очікуваний та фактичний результат, виправ помилку.
  8. Збережи city.py, зроби скриншот результату та короткий висновок: яку проблему розв'язала процедура?

Критерії оцінювання (12 балів)

Вікно та Canvas — 2; коректна процедура з параметрами — 3; три різні виклики — 2; додатковий об'єкт — 1; тести та виправлення — 2; збереження, висновок і зазначення джерел — 2.

Як симуляція пов'язана з Python?

На кожному етапі з'являється частина будинку: основа, дах, вікно, двері. Параметри x, y, size, roof_color відповідають аргументам процедури draw_house. Симулятор — навчальна модель, а не інтерпретатор Python.
