Як працює лінійна програма?

Проблемне запитання: як комп'ютер швидко обчислить вартість екскурсії для всього класу, якщо відома ціна квитка та дороги?

⌨️ Введення→⚙️ Обчислення→🖥️ Виведення

Лінійний алгоритм

Кроки виконуються один за одним у записаному порядку: без розгалужень і повторень.

Змінна

Іменована ділянка пам'яті для значення. price = 80 — приклад присвоювання.

Введення

input() отримує рядок. Для цілого числа застосовують int(input()).

Обчислення

Python підтримує +, -, *, /, //, %.

Виведення

print() показує значення; можна поєднувати текст і змінні.

Тестування

Порівнюй відповідь програми з ручним розрахунком на кількох наборах даних.

Типова помилка: pupils = input(), а далі pupils * 80. Рядок, помножений на 80, повториться 80 разів, а не обчислить вартість. Для кількості учнів використай int(input()).

Мініприклад

pupils = int(input("Скільки учнів? "))
ticket = 80
total = pupils * ticket
print("Разом:", total, "грн")

Для 5 учнів отримаємо 400 грн. Команди виконуються згори донизу.

03 · Практична місія · 15 хв

Проєкт «Плануємо екскурсію»

Мета: створити програму для підрахунку загальної вартості квитків і дороги. Інструменти: Python 3 (IDLE або онлайн-редактор). Підготовка: перевір роботу клавіатури, відкрий редактор, не вводь особистих даних.

  1. Крок 1. Відкрий Python IDLE або перевірене онлайн-середовище Python та створи новий файл.
  2. Крок 2. Запиши назву проєкту в коментарі: # Вартість екскурсії.
  3. Крок 3. Отримай кількість учнів: pupils = int(input('Кількість учнів: ')).
  4. Крок 4. Отримай ціну квитка: ticket = float(input('Ціна квитка, грн: ')).
  5. Крок 5. Отримай вартість дороги для одного учня: travel = float(input('Дорога для одного, грн: ')).
  6. Крок 6. Обчисли total = pupils * (ticket + travel).
  7. Крок 7. Виведи print('Загальна вартість:', total, 'грн') і перевір значення 5, 80, 20 → 500 грн.
  8. Крок 8. Збережи файл excursion.py; перевір ще набори 1, 50, 0 → 50 грн і 0, 80, 20 → 0 грн.
# Вартість екскурсії
pupils = int(input("Кількість учнів: "))
ticket = float(input("Ціна квитка, грн: "))
travel = float(input("Дорога для одного, грн: "))
total = pupils * (ticket + travel)
print("Загальна вартість:", total, "грн")
Очікуваний результат: файл excursion.py, який для 5 учнів, квитка 80 грн і дороги 20 грн обчислює 500 грн. Перевір три набори даних. Критерії: введення 3 значень, правильна формула, читабельний вивід, успішні тести.
