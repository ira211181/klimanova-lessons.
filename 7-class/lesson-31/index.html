Поняття • приклади • помилки

Один алгоритм — багато фігур

Що таке процедура?

Процедура — іменований блок команд, який виконує певну дію після виклику. У Python її оголошують ключовим словом def. Процедура малювання змінює зображення на полотні, навіть якщо не повертає значення через return.

Параметри — назви змінних в оголошенні, наприклад x, y, base. Аргументи — конкретні значення під час виклику, наприклад 40, 70, 120.

Чому це корисно? Замість трьох копій графічного коду достатньо одного визначення та трьох викликів. Зміна алгоритму одразу вплине на всі наступні виклики.

Координати Canvas

У вікні початок координат — лівий верхній кут, x зростає праворуч, y — униз.

Робочий приклад Python: «Трикутна галерея»

from tkinter import Tk, Canvas

root = Tk()
root.title("Трикутна галерея")
canvas = Canvas(root, width=500, height=340, bg="white")
canvas.pack()

def triangle(x, y, base, height, color):
    # x, y — верхній лівий кут області фігури
    # Вершина трикутника розташована над основою
    canvas.create_polygon(
        x, y + height,
        x + base // 2, y,
        x + base, y + height,
        fill=color, outline="navy", width=3
    )

triangle(30, 40, 100, 120, "skyblue")
triangle(180, 70, 140, 170, "gold")
triangle(360, 35, 80, 95, "salmon")
root.mainloop()

Пояснення команд

def triangle(...): оголошує процедуру; усі рядки її тіла мають однаковий відступ. create_polygon() з’єднує три вершини. base // 2 знаходить цілу половину основи. triangle(...) запускає малювання з новими аргументами.

Типові помилки

❌ Немає двокрапки після def.
❌ Різні відступи в тілі процедури.
❌ Процедуру описано, але жодного разу не викликано.
❌ Передано не ту кількість аргументів.
❌ Координати виводять фігуру за межі Canvas.

Дослідницьке запитання: що зміниться, якщо у третьому виклику збільшити base із 80 до 140, не змінюючи x?

Створюю власний проєкт

Практична робота «Трикутний парк»

Завдання: створити у Python Tkinter парк із щонайменше чотирьох кольорових трикутних дахів або дерев, використовуючи одну процедуру з параметрами.

  1. Створи новий файл triangle_park.py у Python IDLE.
  2. Імпортуй Tk і Canvas, створи вікно та полотно 500×340.
  3. Оголоси def triangle(x, y, base, height, color): з правильним відступом.
  4. У тілі процедури використай canvas.create_polygon() для трьох вершин.
  5. Виклич процедуру для двох фігур із різними координатами.
  6. Додай ще дві фігури, змінивши розміри та кольори без копіювання тіла процедури.
  7. Перевір крайні випадки: маленьку основу та розміщення біля правого краю полотна.
  8. Збережи файл і зроби знімок екрана готової програми; коротко поясни, чому використання процедури зручне.

Оцінювання (12 балів)

Створення вікна й полотна — 2; правильна процедура — 3; аргументи й 4 виклики — 3; оформлення — 2; перевірка та пояснення — 2.

Безпечна робота

Зроби перерву для очей, сядь зручно, не відкривай підозрілі файли, зберігай роботу у власній навчальній папці. Не публікуй особистих даних у знімках екрана.
