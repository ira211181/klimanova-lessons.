02

Редактор проєкту Python IDLE

Текст проєкту — послідовність команд, записаних мовою програмування. IDLE містить текстовий редактор, консоль, засоби запуску та підказки.

П'ять дій

  1. File → New File — створити файл.
  2. Увести код із правильними лапками та дужками.
  3. File → Save — зберегти як vikno.py.
  4. Run → Run Module або F5 — запустити.
  5. Прочитати результат або повідомлення про помилку.

Що допомагає редактор

Підсвічування синтаксису, автодоповнення, підказки аргументів, підсвічування парних дужок, автоматичні відступи після двокрапки.

Важливо: підказки не гарантують відсутності помилок. Потрібна власна перевірка.

Мінімальний віконний проєкт

from tkinter import Tk
root = Tk()
root.title('Моя майстерня')
root.geometry('320x220')
root.mainloop()

Tk() створює вікно; title() задає заголовок; geometry() — розміри; mainloop() забезпечує роботу вікна з подіями.

03

Діагностика помилок

SyntaxError

Порушення правил запису: незакриті лапки чи дужки, пропущена двокрапка після if. Інтерпретатор не може розібрати програму.

root.title('Вітаю)
# Пропущена лапка

Інші помилки

TK() замість Tk() може викликати NameError, а root.titel() — AttributeError. Неправильний заголовок за успішного запуску — логічна помилка.

root = TK()
# Неправильний регістр

Алгоритм: прочитай повідомлення → знайди проблемний рядок → визнач правило → виправ → збережи → перевір повторно. Причина іноді міститься в попередньому рядку.

Правильно: root.geometry('300x200'). Некоректно: root.geometry(300x200) — розміри потрібно передавати рядком у лапках.

05

Практична робота «Редактор без помилок»

Працюй у Python IDLE на комп'ютері з графічним інтерфейсом. Якщо такого середовища немає, виконай браузерні вправи нижче та повідом учителя, що справжній запуск не здійснювався.

  1. Відкрий IDLE та обери File → New File.
  2. Уведи код із розділу «Теорія».
  3. Збережи його як vikno_redaktor.py.
  4. Натисни F5 та перевір появу вікна.
  5. Зміни заголовок на «Мій редактор», розміри — на 360x240.
  6. Навмисно вилучи одну закривну лапку та спробуй запуск.
  7. Прочитай повідомлення, поверни лапку, збережи й запусти знову.
  8. Поясни вчителю, що було помилкою та як ти її виправив/виправила.

Критерії (12 балів): збережений файл — 2; коректний код — 3; діагностика — 3; виправлення й пояснення — 4.
