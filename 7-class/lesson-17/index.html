02Теорія: як програма ухвалює рішення

Розгалуження — алгоритмічна структура, у якій вибір дій залежить від результату логічної умови. Умова має значення True або False.

Порівняння

== дорівнює, != не дорівнює, > більше, < менше, >= не менше, <= не більше.

Умовні команди

if — якщо; elif — інакше якщо; else — інакше. Після умови потрібна двокрапка.

Логічні операції

and — обидві умови; or — принаймні одна; not — заперечення.

Приклад 1. Повне розгалуження

age = int(input("Скільки тобі років? "))
if age >= 18:
    print("Доступ дозволено")
else:
    print("Доступ заборонено")

Якщо age=18, виконається перша гілка. Якщо age=17 — друга. Зверни увагу на відступи!

Приклад 2. Кілька умов

score = 9
if score >= 10:
    print("Високий результат")
elif score >= 7:
    print("Добрий результат")
else:
    print("Потрібне тренування")

Перевірки виконуються зверху вниз, і в цьому ланцюжку виконується лише одна гілка.

Типові помилки: замість == записано =; пропущено :; немає відступу; порівняно рядок із числом без перетворення типу; не перевірено граничні значення.
