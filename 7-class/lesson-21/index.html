Критерії успіху

Можу написати дві взаємопов’язані функції, пояснити трасування, передбачити результат і перевірити програму щонайменше на трьох наборах даних.

02 · SMART LAB

Теорія: одна задача — кілька функцій

1. Декомпозиція

Складне завдання зручно поділити на менші: перевірка введення, обчислення базової суми, застосування знижки, формування повідомлення.

2. Повернення результату

return передає значення в місце виклику. print лише виводить інформацію. Якщо функція нічого явно не повертає, результат її виклику — None.

3. Композиція

Функція final_cost() може викликати base_cost(), отримати результат і застосувати правило знижки.

4. Тести

Для порога знижки від 10 учнів перевір 9, 10 і 11. Для ціни — 0, додатне число та помилкове від’ємне значення.

Типові помилки: забути return; переплутати 10 % і 0.1; використати змінну до присвоювання; не перевірити від’ємну ціну або нульову кількість.

03 · SMART LAB

Приклади Python з поясненнями

Спосіб 1: усе в одному блоці — складно перевіряти

count = 12
price = 90
discount = 10
total = count * price * (1 - discount / 100)
print(total)

Спосіб 2: окремі функції — зрозуміло та повторно використовувано

def base_cost(count, price):
    return count * price

def final_cost(count, price, discount_percent):
    subtotal = base_cost(count, price)
    if count >= 10:
        return subtotal * (1 - discount_percent / 100)
    return subtotal

print(final_cost(12, 90, 10))  # 972.0
print(final_cost(9, 90, 10))   # 810

Спочатку base_cost повертає 1080. Потім final_cost зменшує суму на 10 %: 1080 − 108 = 972 грн. Для 9 учнів поріг не досягнуто, тому знижка не застосовується.

Мініексперимент: заміни return count * price на print(count * price). Чому обчислення знижки перестане працювати? Тому що subtotal отримає None.
