2

Теорія: як програма обирає шлях

1. Аналіз умови

Розгалуження — це алгоритм, у якому виконання команд залежить від істинності логічного виразу. Python перевіряє if, за потреби наступні elif, а else виконує за відсутності попередніх збігів.

2. Перевірка меж

Відмінність між < і <= особливо помітна на граничних значеннях. Для віку перевіряй 5, 6, 17, 18 років.

3. Введення

input() повертає текст. Для цілого числа застосовуй int(input()), а для надійної програми — обробку помилок введення.

Приклад: тариф квитка

age = int(input("Вік: "))
student = input("Студент? так/ні: ").lower() == "так"

if age < 0:
    print("Некоректний вік")
elif age < 6:
    print("0 грн")
elif age <= 17:
    print("50 грн")
elif student:
    print("70 грн")
else:
    print("100 грн")

Типові помилки

= замість ==; відсутня двокрапка; пропущено відступ; рядок порівнюють із числом; неправильний порядок умов.

Перевір себе

Чому перевірку age < 6 потрібно поставити раніше, ніж age <= 17? Інакше маленькі діти потраплять до дитячого платного тарифу.

Практична робота «Квиткова каса»

Створи власну Python-програму для розрахунку ціни квитка. Працюй у локальному редакторі Python або дозволеному вчителем онлайнсередовищі. Не вводь справжні персональні дані.

  1. Запиши мету програми, вхідні дані (age, student) та вихід (вартість).
  2. Створи файл ticket.py і додай пояснювальний коментар.
  3. Отримай вік за допомогою int(input(...)).
  4. Запитай про статус студента (так/ні) та перетвори відповідь на логічне значення.
  5. Додай перевірку від’ємного віку й послідовність if / elif / else.
  6. Виведи зрозумілий результат із сумою у гривнях.
  7. Перевір випадки: −1, 5, 6, 17, 18, 19 років; окремо — повнолітній студент.
  8. Зроби висновок, додай 2 скриншоти тестів і поясни, чому порядок перевірок важливий.
Безпека та чесність: працюй лише у схваленому середовищі; якщо користуєшся підказкою ШІ, зазнач це у звіті. Код перевіряй самостійно.

Критерії: правильні умови (4 б.), тестування меж (4 б.), зрозумілий код (2 б.), висновок та авторство (2 б.).

Натисни «Крок», щоб почати.
