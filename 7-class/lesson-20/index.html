02 · Теорія підпрограм

Підпрограма — іменований блок коду для повторного використання.
Параметр — ім’я змінної у визначенні функції.
Аргумент — значення, передане під час виклику.
return — команда повернення значення.
Виклик — запуск функції за назвою.
Локальна змінна — зазвичай доступна тільки у функції.

Схема: виклик → аргументи → параметри → виконання тіла → return.

Типова помилка: забута двокрапка, неправильні відступи або використання print замість return.

Офіційне видання Ривкінда, 7 клас; параграф потребує перевірки.

03 · Приклади з поясненнями

def vitai(imia):
    print("Вітаю, " + imia)

vitai("Олена")
vitai("Ілля")

Одна функція виконує ту саму дію з різними аргументами.

def ploshcha(a, b):
    return a * b

s = ploshcha(4, 6)
print(s)  # 24

На відміну від print, return дозволяє використати число в подальших обчисленнях.

def vartist(vik, uchen):
    if vik < 6:
        return 0
    if uchen:
        return 50
    return 100

05 · Практична робота «Квиткова каса»

Мета: написати функцію для вартості квитка. Інструмент: Python 3. Безпека: лише вигадані дані.

  1. Створіть файл kasa.py.
  2. Напишіть def vartist(vik, uchen):.
  3. Для vik < 6 поверніть 0.
  4. Для uchen == True поверніть 50.
  5. В інших випадках поверніть 100.
  6. Викличте функцію для (5,False), (12,True), (30,False).
  7. Перевірте очікувані результати 0, 50, 100.
  8. Збережіть файл і поясніть відмінність print та return.
Критерії: відступи, три виклики, три правильні результати, пояснення. Додатково — обчислення суми кількох квитків.
