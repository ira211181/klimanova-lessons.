01

Навіщо це вивчати?

Знати

Що містить об’єкт event і як працюють функції-обробники.

Уміти

Прив’язувати події миші та клавіатури й змінювати властивості вікна.

Перевіряти

Прогнозувати результат для різних координат і виправляти помилки.

Пригадай: у попередньому уроці ми з’ясували, що таке подія. Сьогодні зосередимося на даних події, кількох обробниках і тестуванні.

02

Обробник — реакція програми

Подія → функція → дія

Подія — клацання, рух миші, натискання клавіші. Обробник — функція, яку викликає Tkinter, коли виникає відповідна подія.

root.bind('<Button-1>', on_click) зв’язує клацання з функцією. Не пишемо on_click() у bind: це виклик функції, а не посилання.

Об’єкт event

event.x — координата X; event.y — координата Y відносно віджета, що отримав подію; event.keysym — назва натиснутої клавіші для клавіатурної події.

Координати змінюються залежно від місця клацання. Саме тому один обробник може давати різні результати.

<Button-1>

Клацання основною кнопкою.

<Double-Button-1>

Подвійне клацання.

<Motion> / <Key>

Рух вказівника / клавіатура.

Динамічні властивості: root.winfo_width() і root.winfo_height() повертають поточні розміри; root.geometry('420x260') змінює їх. Після створення вікна перед першим читанням геометрії іноді потрібне root.update_idletasks().

03

Приклад: «Розумне вікно»

Після клацання програма читає координати та змінює заголовок. Подвійне клацання повертає початковий колір. Для клавіші Пробіл передбачено окрему реакцію.

import tkinter as tk

root = tk.Tk()
root.title("Розумне вікно")
root.geometry("380x240")
root.configure(bg="lightblue")

def on_click(event):
    root.title(f"Клацання: x={event.x}, y={event.y}")
    if event.x < 190:
        root.configure(bg="lightgreen")
    else:
        root.configure(bg="lightyellow")

def on_double(event):
    root.configure(bg="lightblue")
    root.title("Розумне вікно")

def on_key(event):
    if event.keysym == "space":
        root.geometry("420x260")

root.bind("<Button-1>", on_click)
root.bind("<Double-Button-1>", on_double)
root.bind("<Key>", on_key)
root.mainloop()

Подвійне клацання в деяких системах може спричинити також подію одинарного клацання. Тому окремі обробники варто тестувати разом. Для клавіатурних подій вікно повинне мати фокус вводу.

04

Знайди та виправ помилку

❌ root.bind("<Button-1>", on_click())

Функція викликається завчасно. Передай її назву без дужок: on_click.

❌ def on_click(): print(event.x)

Обробник, прив’язаний через bind, має приймати аргумент події: def on_click(event):.

❌ Нескінченне збільшення вікна

Обмежуй розмір, наприклад min(800, width + 20), щоб вікно залишалося керованим.

❌ «Клавіші не працюють»

Перевір, чи вікно активне та має фокус; після запуску клацни в ньому.

06

Практична робота «Вікно-детектив»

Мета: створити власне вікно, яке розпізнає місце клацання та реагує на клавішу. Працюй у Python IDLE або іншому середовищі з підтримкою Tkinter.

  1. Створи новий файл vikno_detektyv.py і підключи tkinter.
  2. Створи вікно 400×260 пікселів із заголовком «Вікно-детектив».
  3. Опиши def on_click(event): та виводь координати в заголовку.
  4. За умовою event.x < 200 змінюй фон на зелений, інакше — на жовтий.
  5. Додай def on_double(event): для повернення початкового кольору.
  6. Додай обробник <Key>: натискання пробілу встановлює розмір 450×280.
  7. Зв’яжи всі події через bind() і запусти mainloop().
  8. Протестуй: ліву й праву частини, подвійне клацання, пробіл. Запиши, що відбулося.
Критерії (12 балів): вікно й код — 3; два обробники миші — 3; клавіатура — 2; тестування чотирьох сценаріїв — 2; пояснення й охайність — 2.

Безпека: не завантажуй невідомі програми, не змінюй системні налаштування, роби короткі перерви для очей.
