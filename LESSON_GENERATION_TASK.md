## Робочий цикл до завершення навчального року
1. Зчитати КТП; визначити уроки від наступного ще не опублікованого номера до кінця 2026/2027 для кожного класу 5–11. Зіставити клас, номер, тему та дату; не вигадувати дат і параграфів.
2. Перевірити в GitHub наявність кожного уроку, не перезаписувати вручну змінені файли без потреби. Починати з найближчих за календарем уроків; готувати наступні заздалегідь.
3. Для кожного уроку створити окремий адаптивний `<grade>-class/lesson-<number>/index.html`, з усіма локальними JS/CSS та потрібними assets.
4. Обов'язкова структура: hero, липка навігація, теорія (поняття, приклади, помилки), реальний український YouTube iframe 16:9 із двома контрольними запитаннями, практична робота 4–8 кроків, щонайменше дві авторські інтерактивні вправи, предметна симуляція з кроком/автозапуском/паузою/скиданням/поясненням, 20 різнотипних тестових запитань із перевіркою та розбором, домашня робота трьох рівнів і 8–10 окремих тестових питань, рефлексія та академічна доброчесність.
5. **Підручник Ривкінда є обов'язковим у кожному уроці**: видимий блок/кнопка «Підручник» з реальним перевіреним посиланням саме для цього класу, дублювання в джерелах. Перевіряти видання/авторів і відповідність КТП; якщо конкретний параграф не підтверджено — написати «параграф потребує перевірки», не вигадувати. Якщо для певного класу немає підтвердженого видання Ривкінда, позначити це як блокер, не підставляти підручник іншого класу.
6. Відео: спочатку шукати канал учителя https://www.youtube.com/@ІринаВолодимирівнаКліманова/videos; якщо немає відповідного — інший український освітній канал. Перевіряти URL і можливість вбудовування; не вставляти неперевірені ID. Wordwall — лише перевірені публічні вправи; інакше власні JS-вправи.
7. Тестувати синтаксис JS, відсутність порожніх посилань, роботу всіх кнопок, доступність із клавіатури, мобільну адаптивність, коректність тестів і відповідей, наявність реального iframe, посилання на підручник та навігацію.
8. Публікувати через GitHub у репозиторій `ira211181/klimanova-lessons.`, гілка `main`. Не перезаписувати кореневий `index.html`, який належить іншому уроку. Оновлювати журнал створених/пропущених уроків. GitHub Pages має бути активовано в Settings → Pages → GitHub Actions; не заявляти про відкритий сайт без перевірки URL.
9. Якщо бракує джерел/доступу або публікація неможлива — звітувати про точну перешкоду, а не видавати файл за опублікований сайт.

## Критерій готовності
Кожен урок відповідає КТП і стандарту 5.0, містить працюючі інтерактиви, 20 тестів, вбудоване українське відео та підтверджене посилання на відповідний підручник Ривкінда. У звіті: клас, номер, тема, GitHub commit, посилання на сторінку (лише як підтверджене чи очікуване), відсутні перевірки.
