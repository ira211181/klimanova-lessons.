05 · Теорія (19–24 хв)

Сортування — упорядкування значень за критерієм. Метод sort() змінює наявний список, функція sorted() повертає новий відсортований список.

scores = [9, 5, 12, 7, 10]
scores.sort()
print(scores) # [5, 7, 9, 10, 12]
scores.sort(reverse=True)
print(scores) # [12, 10, 9, 7, 5]
values = [8, 2, 5]
new_values = sorted(values)
print(values)     # [8, 2, 5]
print(new_values) # [2, 5, 8]

Типова помилка: result = scores.sort() не створює новий список: метод повертає None. Вбудоване сортування Python зазвичай доцільніше за власну реалізацію бульбашкового алгоритму.

Підручник: Ривкінд та ін., § 3.3, с. 117–122 (за КТП).
